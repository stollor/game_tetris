# NEON PULSE · 俄罗斯方块

基于 Bun、TypeScript 与 Phaser 的单机网页俄罗斯方块。实现内容以 `策划案/02` 到 `策划案/07` 为准，包含正式 SRS 规则、四种模式、菜单、设置、本地纪录与霓虹街机界面。

## 启动

```sh
bun run dev
```

## 模式

- **马拉松**：逐级提速，以高分与存活时间挑战 140 行目标；达标后继续无尽。
- **冲刺 Sprint**：最快消满 40 行；有效用时排除暂停，失败不写完赛纪录。
- **极限 Ultra**：在 120 秒内冲击高分；暂停冻结计时。
- **每日挑战**：UTC 日期固定随机种子，同日重开序列不变；成绩按日期单独保存。

SRS 旋转、JLSTZ / I 踢墙表、180° 旋转、隐藏行、7-bag、500ms 锁定延迟、DAS/ARR、T-Spin、Combo、B2B、Perfect Clear 和软降/硬降计分由各模式共用。

## 操作

- ← / → 移动并按住连续横移；↑ 或 X 顺时针旋转；Z 旋转 180°。
- ↓ 软降；空格硬降；P / Esc 暂停和恢复。
- 结算页可重开或返回主菜单；马拉松结算 3 秒内忽略重开。

主菜单的“180°旋转”开关控制 Z 键半转，默认开启。

主菜单提供四种模式和通用设置（音量、主题、样式、语言）。个人纪录保存在浏览器本地存储。

## 检查

```sh
bun run check
bun run typecheck
bun test
bun run build
bun run test:browser -- http://localhost:3000
```

正式版状态流程由 GameMaker 执行：

```sh
bun run gm -- browser test 俄罗斯方块 http://localhost:3000 测试/正式版核心流程/状态机.json
```

浏览器验收截图保存在 `测试/正式版浏览器验收/`，菜单、场景状态、键盘长按和游戏字段断言证据保存在 `测试/正式版核心流程/`。固定序列测试接口只在 localhost 暴露。
