# 再消一行

声音条件写在对局对照场景里。`性能实验.ts` 在准备和完成时读回实际设置与播放器调用，条件不符即失败；框架创建/销毁流量和项目音频专项随GM报告保存。看板「对照」默认跑完全部对照场景，15秒两轮、每秒8次真实落块、串行，也可只勾选声音相关项。历史小数音量对照，以及已撤下的 `audio-confirm`、`duel-confirm` 记录，只读保留。

旅行版新增12套地域外观，每套包含静态/动态背景、界面主题、方块质感与纹样、17项音效和一首原创程序音乐。通过有效对局、每日首局、破纪录与成就获得金币，在「商店」按部位购买或折扣补齐整套。定价、奖励、保存边界与TapTap H5上线限制见 [旅行版说明](文档/旅行版说明.md)。旧外观、旧纪录和游戏目录保留。

基础三套主题采用夜空金紫、古典红金与未来青蓝，共用 `代码/框架配置/界面主题.ts`；风景背景和方块质感独立选择。GM UI 套件选中组件后可「放大查看／返回总览」，样式、背景与方块外观卡使用可横向移动的单排列表。主题实机检查运行 `bun 测试/浏览器/方块外观.ts http://127.0.0.1:3220 --主题`，覆盖 1280/430 下的选择、保存、刷新和对局画面，结果在 `reports/interface-themes/`。

基于 Bun、TypeScript 与 Phaser 的单机网页方块消除游戏《再消一行》。当前 GM 看板识别的功能策划入口是 [`文档/功能策划/README.md`](文档/功能策划/README.md)；原 `策划案/00-08` 保留为早期分阶段 Agent 能力测试来源，不代表现行功能仍未实现。

## 启动与构建

```sh
bun run dev       # 构建并启动开发服务器
bun run build     # 构建到 产物/
```

性能现状与后续事项见[性能优化待办](文档/性能优化待办.md)和[性能与耗电](文档/性能与耗电.md)。

GM 看板「测试 → 性能」与 `gm 浏览器 性能` 共用项目`测试/浏览器/性能场景.ts`：基础9项、逐项关闭对照10项和真实资源压力20个档位。框架提供帧、耗时、对象、贴图、音频、并发队列与资源调度；`代码/开发/性能观测.ts`追加项目缓存与压力创建/清理指标。资源统计只读既有缓存。旧服务需重启后重新检测，贴图RGBA8与声源数不能直接换算手机电耗。

看板性能入口是基准、对照、压力三类，自动启动游戏、执行并匹配同条件历史基线。基准覆盖菜单、对局、暂停和完赛。对照可全量或勾选场景，并调整轮数、每轮秒数和每秒落块次数。压力沿用资源阶梯，并发2只做筛查。旧记录按实际配置归组。CLI仍保留单项与参数化检查入口。

资源目录在`代码/开发/压力资源.ts`，直接调用落块/消行特效、真实方块绘制、合成音效与对局曲谱；`压力场景.ts`仅通过框架loopback开发页`?gm-stress=1`运行，使用正常测试桥。对象铺在屏内，方块共享贴图；停止清理自有实例/输出，不关闭共享音频上下文。`性能开关.ts`的`gm-disable`仅本机有效，不写存档，用于关闭落块、消行或计时文字以比较实际贡献。

实验脚本在`测试/浏览器/性能实验.ts`；数量倍率、每秒次数、恢复期和时长独立。持续对局真实按键、逐块验证、40行后同页重开。对局基线明确使用音乐/环境声15、音效80，不代表玩家当前设置。资源压力可并行筛查，候选用并发1复测；容量超限会失败，不悄悄降低请求量。

## 配置表

`配置/配置表.json` 保存当前对局的运行值：模式目标（马拉松 140 行、冲刺 40 行、冲刺等级上限 5、极限 120 秒）、锁定延迟（500ms）与锁定重置上限、逐档下落速度。`代码/项目配置/模式.ts` 读取并校验表编号后导出 `模式配置`、`节奏配置`、`速度表`，`代码/玩法/再消一行.ts` 直接引用，不再各写常量。规则与结算仍由玩法代码决定。

## 模式

- **马拉松**：逐级提速，以高分与存活时间挑战 140 行目标；达标后继续无尽。
- **冲刺 Sprint**：最快消满 40 行；有效用时排除暂停，失败不写完赛纪录。
- **极限 Ultra**：在 120 秒内冲击高分；暂停冻结计时。
- **每日挑战**：UTC 日期固定随机种子，同日重开序列不变；成绩按日期单独保存。

SRS 旋转、JLSTZ / I 踢墙表、180° 旋转、隐藏行、7-bag、500ms 锁定延迟、DAS/ARR、T-Spin、Combo、B2B、Perfect Clear 和软降/硬降计分由各模式共用。

## 操作

- ← / → 移动并按住连续横移；↑ 点按按设置方向旋转（默认左转）、长按 450ms 暂存，X 逆时针旋转；Z 旋转 180°；C 暂存换块。触屏 ↑ 同样支持长按暂存。
- ↓ 软降；空格硬降；P / Esc 暂停和恢复。
- 结算页可重开或返回主菜单；马拉松结算 3 秒内忽略重开。

主菜单的“180°旋转”开关控制 Z 键半转，默认开启。主菜单提供四种模式和通用设置（音量、主题、样式、语言）；个人纪录保存在浏览器本地存储。

## GameMaker 框架

本机 `框架/` 目录联接到 GameMaker 仓库的 `游戏模块库/Phaser框架/`，游戏 Git 忽略该目录，只提交玩法与游戏专属界面代码。云端打包使用运行该任务的 GM 主干 checkout 中的最新框架。

已复用的能力：

- 菜单统一使用 `框架/界面/按钮.ts` 的按下、松开、取消和销毁协议；用 `响应式视口.ts` 适配窄屏及短横屏；顶部数值接入 `数值面板.ts` 的变化动画。
- 背景音乐与音效走 `框架/音频/`：曲谱与合成谱登记在 `代码/框架配置/`。菜单和对局默认不播曲，商店选地点即试听该套音乐；风景环境声走 `播放场景氛围`。操作音效按通道节流。见 `文档/音频接入.md`。
- `代码/存档/对局纪录.ts` 接入 `框架/存档.ts`，保留 `neon-pulse:best:*` / `neon-pulse:daily:*` 键和旧裸 JSON 格式，兼容只含分数的早期纪录；损坏、非法或未知格式不会被结算覆盖。
- 设置与商店等长列表走 `框架/界面/滚动区域.ts`：镜头视口裁剪替代每帧离屏滤镜遮罩，并开启惯性；一次拖动只归一个滚动区域。
- 高 DPR 清晰度与省电接入框架 `画布像素比`：两档均保留最高 4 倍精度；操作区14px文字分行显示，冻结操作画面与棋盘画面层按屏幕物理像素合成，保留高清字形与方块。标准限 60 帧、省电限 30 帧。慢速背景分别按 10/5 帧更新，菜单/商店闲置后降至 2 帧；关闭背景动态后停止背景重绘，见 `代码/性能/画质.ts`。
- 静态装饰只在布局时绘制；静态面板、缩略图与整屏底图复用烘焙纹理，动态层按背景节拍直接绘制，避免每次先烘焙再贴回屏幕。菜单、纯享和暂停空闲时使用 Phaser 休眠与定时推进，输入立即唤醒；对局保持标准60/省电30帧。按需渲染跳过无变化帧，暂停的补间不触发持续重画；棋盘及预览栏按显示签名重绘。
- 落块拖尾与锁闪复用4个拖尾和1个锁闪图形子对象，只在硬降/锁定时重建几何，动画仅改缩放与透明度并沿用自动图形烘焙；冲刺实时计时文字按50ms整桶刷新（约20次/秒，最大滞后小于50ms），暂停、结算与成绩仍取精确有效用时。
- `bun 测试/浏览器/性能优化验收.ts <游戏地址> 优化后` 检查390×844下的实时计时刷新、暂停精度、拖尾几何复用、特效到期与清空，截图和回执在 `reports/performance-optimization/`。性能收益仍通过原性能场景的新旧对照确认。
- `bun 测试/浏览器/清晰度与省电验收.ts http://127.0.0.1:3221` 验证390×844手机模拟下的DPR 1/3/3.25、标准/省电、动态/静态背景、文字尺寸与合成纹理物理精度、触屏操作、暂停恢复、缓存缩放失效与限帧计时，报告和截图在 `reports/mobile-power/`。脚本包含无开发桥的正式渲染路径采样，不代表手机真机续航测量。
- 空闲调度、输入、音频与性能采样见 [性能与耗电](文档/性能与耗电.md)。程序音频复用框架的 Phaser 上下文；环境声音量为零时不生成循环声源，失焦/切后台清理声源与点缀定时器，恢复后按设置重建。

方块规则、数值、模式目标和种子沿用现有实现。货币分级、离线收益及经营动画属于包子铺的需求，没有强行接入再消一行。

## 测试分层

正式包通过 GM `bun run gm -- 打包游戏 再消一行` 生成到 `产物/`，该入口清理旧哈希文件、压缩并外置 Phaser，报告见 `文档/打包报告.md`。`bun run build` 仅用于普通构建检查，不执行正式包清理和优化。TapTap 应用编号、16 个排行榜 ID、成就映射、测试包版本与真机坑见 [TapTap 项目手册](文档/TapTap项目手册.md)；通用打包上传流程见 GM `文档/TapTap发布.md`。

1440×900 是界面尺寸基准，不是发布分辨率上限。Canvas 随窗口实际尺寸调整；大屏时菜单、棋盘、HUD和覆盖面板通过框架 `适配场景视口` 同步放大，较小视口保持手机/紧凑布局重排，超宽屏保留更多横向背景。程序化图形重新绘制，文字纹理随放大提高精度。窗口重排保留当前对局。

运行 `bun 测试/浏览器/分辨率适配.ts` 直接验收当前 `产物/`（无需开发服务），覆盖320像素窄屏、手机高像素比、短横屏、1080p、2K、4K与超宽屏的菜单、设置滚动、成就、暂停设置和对局重排，截图和结果存入 `reports/resolution/`。设备像素比为浏览器模拟，不能代替手机真机或性能验收。

- 规则/状态机/纯函数：`测试/*.test.ts`（如 `玩法.test.ts`、`暂存技巧.test.ts`、`消行事件.test.ts`、`成就.test.ts`、`纪录.test.ts`），用 `bun test`。
- 实机脚本：`测试/浏览器/*验收.ts`、`测试/浏览器/视觉快照.ts`，用 Playwright 跑真实页面检查点击、视口、截图与发声，不使用 `*.test.ts` 后缀。
- 旅行商店和地域外观：`bun 测试/浏览器/旅行版.ts`，直接读取正式发布包，覆盖购买/穿戴/保存、真实成就与对局奖励、12套皮肤；`bun 测试/浏览器/旅行音频.ts` 对12首音乐和204项音效做Web Audio采样，输出在 `reports/travel/`、`reports/travel-audio/`。
- 视觉与状态机产物目录不提交；实际发声与节流由 `测试/浏览器/落块体验验收.ts` 采集音效样本验证。

几何或截图采集只代表界面/发声层面的结果，不代表完整玩法验收；业务验收仍需实际的规则与交互检查。

设置中的音乐、音效与背景音效用滑块调节；背景音效默认关闭。商店纯享入口位于套件面板上方，退出位于屏幕底部，方块陈列使用地点主题底板。

货币以金色 O 形四格方块呈现，称为方块币；沿用原存档字段与余额。设置外观卡可直接横拖，竖拖滚动页面；背景音效使用独立氛围输出，音乐、交互音效和氛围分别调节。

音乐滑块会同步保存启用状态，首次与恢复默认均为0；菜单和对局登记当前曲目，调高音量即可播放。一次触屏拖动在确定方向后只归一个滚动区域，横拖穿过相邻外观行也不会带动它们。

“10分钟多局检查”使用`冲刺长时多局`场景，日常在同一页面至少运行600秒，30分钟仅用于专项排查，三局一批真实完赛重开，每批固定恢复点核对空棋盘、音量、累计局数与落块量。每批记录游玩和恢复两段，避免逐局阶段超过工具容量；超出90批明确失败。自动落子偏差保留实际状态、计划与按键耗时，不自动纠正或重试。长测为受控固定七袋条件，不等于真机或全部随机局面验收。
