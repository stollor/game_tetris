# 俄罗斯方块 旅行版

旅行版新增12套地域外观，每套包含静态/动态背景、界面主题、方块质感与纹样、16项音效和一首原创程序音乐。通过有效对局、每日首局、破纪录与成就获得金币，在「商店」按部位购买或折扣补齐整套。定价、奖励、保存边界与TapTap H5上线限制见 [旅行版说明](文档/旅行版说明.md)。旧外观、旧纪录和游戏目录保留。

基础三套主题采用夜空金紫、古典红金与未来青蓝，共用 `代码/框架配置/界面主题.ts`；风景背景和方块质感独立选择。GM UI 套件选中组件后可「放大查看／返回总览」，样式、背景与方块外观卡使用可横向移动的单排列表。主题实机检查运行 `bun 测试/浏览器/方块外观.ts http://127.0.0.1:3220 --主题`，覆盖 1280/430 下的选择、保存、刷新和对局画面，结果在 `reports/interface-themes/`。

基于 Bun、TypeScript 与 Phaser 的单机网页俄罗斯方块。当前 GM 看板识别的功能策划入口是 [`文档/功能策划/README.md`](文档/功能策划/README.md)；原 `策划案/00-08` 保留为早期分阶段 Agent 能力测试来源，不代表现行功能仍未实现。

## 启动与构建

```sh
bun run dev       # 构建并启动开发服务器
bun run build     # 构建到 产物/
```

## 检查

```sh
bun run check     # Biome 格式与 lint
bun run typecheck # tsc --noEmit
bun test          # Bun 规则测试
bun run build     # 构建
```

浏览器验收脚本串行执行；切换焦点会触发游戏自动暂停，避免并行测试互相干扰：

```sh
bun run test:browser -- http://localhost:3000
bun ./测试/对局HUD验收.ts http://localhost:3000
bun ./测试/落块体验验收.ts http://localhost:3220
bun ./测试/旧版玩法接入验收.ts http://localhost:3000
```

正式版状态流程由外部 GameMaker CLI（`gm`，需单独安装）执行：

```sh
gm browser test 俄罗斯方块 http://localhost:3000 测试/正式版核心流程/状态机.json
```

浏览器验收截图保存在 `测试/正式版浏览器验收/`；固定序列测试接口只在 localhost 暴露。

## 目录

- `代码/玩法/`：SRS、计分、模式目标、随机与每日种子等规则与状态机。
- `代码/项目配置/`：读取 `配置/配置表.json`，向玩法暴露运行参数常量。
- `配置/配置表.json`：运行参数表（见下）。
- `代码/框架配置/`：填给框架的接入表，当前是音乐曲谱与音效合成谱，见其 `README.md`。
- `代码/配置/`、`代码/语言/`：游戏视觉数据与中英文案。
- `组件/`：项目专属 UI 视觉配方（`霓虹街机/`）与 GM 看板组件预览入口（`组件/预览/组件目录.ts`）。见其 `README.md`。
- `代码/界面/`：把 `组件/` 配方接到玩法数据、文案、设置与回调。见其 `README.md`。
- `代码/音频/`：把 `代码/框架配置/` 的谱注册进框架音频总线，保留节流与消行/连击参数。
- `代码/视觉/`、`代码/预制体/`：落块与消行特效、背景绘制、棋盘与预览栏。
- `代码/场景/`：主界面、对局、设置、成就等玩法内容与装配。
- `代码/存档/`、`代码/成就/`：本地纪录与成就。
- `代码/启动.ts`：只填框架选项与加载配置；构建运行脚本在 `运行/`。
- `文档/功能策划/`：GM 看板识别的现行结构化策划索引、功能稿与关系；迁移映射见该目录 `README.md`。
- `策划案/00-08`：保留的早期分阶段能力测试策划来源，不作为现行策划索引。
- `测试/`：规则测试与实机验收脚本（见下）。

项目根 `AGENTS.md` 记录框架复用要求、逐目录读法与测试约定。

## 配置表

`配置/配置表.json` 保存当前对局的运行值：模式目标（马拉松 140 行、冲刺 40 行、冲刺等级上限 5、极限 120 秒）、锁定延迟（500ms）与锁定重置上限、逐档下落速度。`代码/项目配置/模式.ts` 读取并校验表编号后导出 `模式配置`、`节奏配置`、`速度表`，`代码/玩法/俄罗斯方块.ts` 直接引用，不再各写常量。规则与结算仍由玩法代码决定。

## 模式

- **马拉松**：逐级提速，以高分与存活时间挑战 140 行目标；达标后继续无尽。
- **冲刺 Sprint**：最快消满 40 行；有效用时排除暂停，失败不写完赛纪录。
- **极限 Ultra**：在 120 秒内冲击高分；暂停冻结计时。
- **每日挑战**：UTC 日期固定随机种子，同日重开序列不变；成绩按日期单独保存。

SRS 旋转、JLSTZ / I 踢墙表、180° 旋转、隐藏行、7-bag、500ms 锁定延迟、DAS/ARR、T-Spin、Combo、B2B、Perfect Clear 和软降/硬降计分由各模式共用。

## 操作

- ← / → 移动并按住连续横移；↑ 点按顺时针旋转、长按 450ms 暂存，X 逆时针旋转；Z 旋转 180°；C 暂存换块。触屏 ↑ 同样支持长按暂存。
- ↓ 软降；空格硬降；P / Esc 暂停和恢复。
- 结算页可重开或返回主菜单；马拉松结算 3 秒内忽略重开。

主菜单的“180°旋转”开关控制 Z 键半转，默认开启。主菜单提供四种模式和通用设置（音量、主题、样式、语言）；个人纪录保存在浏览器本地存储。

## GameMaker 框架

本机 `框架/` 目录联接到 GameMaker 仓库的 `游戏模块库/Phaser框架/`，游戏 Git 忽略该目录，只提交玩法与游戏专属界面代码。云端打包使用运行该任务的 GM 主干 checkout 中的最新框架。

已复用的能力：

- 菜单统一使用 `框架/界面/按钮.ts` 的按下、松开、取消和销毁协议；用 `响应式视口.ts` 适配窄屏及短横屏；顶部数值接入 `数值面板.ts` 的变化动画。
- 背景音乐与音效走 `框架/音频/`：曲谱与合成谱登记在 `代码/框架配置/`。菜单和对局默认不播曲，商店选地点即试听该套音乐；风景环境声走 `播放场景氛围`。操作音效按通道节流。见 `文档/音频接入.md`。
- `代码/存档/对局纪录.ts` 接入 `框架/存档.ts`，保留 `neon-pulse:best:*` / `neon-pulse:daily:*` 键和旧裸 JSON 格式，兼容只含分数的早期纪录；损坏、非法或未知格式不会被结算覆盖。
- 静态装饰只在布局时绘制；棋盘及预览栏按显示签名重绘；矮横屏下缩小棋盘与侧栏，保留完整棋盘和纪录。

方块规则、数值、模式目标和种子沿用现有实现。货币分级、离线收益及经营动画属于包子铺的需求，没有强行接入俄罗斯方块。

## 界面组件与预览

项目专属 UI 视觉配方在 `组件/霓虹街机/`，对玩法、文案和回调的接入在 `代码/界面/`。配方只接收位置、尺寸、文案和回调，不读存档、不决定规则；颜色统一从 `组件/霓虹街机/调色板.ts` 取。

GM 看板通过 `组件/预览/组件目录.ts` 导出的非空 `组件预览库` 自动发现并预览这些配方，协议 `组件/预览/预览协议.ts` 与 GM 的 `游戏模块库/UI组件库/预览/预览协议.ts` 逐字一致。预览样品的绘制直接调用真实配方。

颜色页将同格式方案按「主题-夜空/古典/青蓝」「方块-默认/柔瓷/铬金/像素」命名。选中色板后在右侧点击「使用此配色」，两组独立应用于相关样品并保留到刷新和交付；GM 预览不写玩家设置。实际游戏可在设置页选择方块外观，棋盘、投影、预告、暂存和特效共用所选方案。颜色与质感数据见 `代码/配置/方块外观.ts`，实机验收运行 `bun 测试/浏览器/方块外观.ts`（默认游戏 3220），结果在 `reports/block-appearances/`。

## 测试分层

正式包通过 GM `bun run gm -- 打包游戏 俄罗斯方块` 生成到 `产物/`，该入口清理旧哈希文件、压缩并外置 Phaser，报告见 `文档/打包报告.md`。`bun run build` 仅用于普通构建检查，不执行正式包清理和优化。

1440×900 是界面尺寸基准，不是发布分辨率上限。Canvas 随窗口实际尺寸调整；大屏时菜单、棋盘、HUD和覆盖面板通过框架 `适配场景视口` 同步放大，较小视口保持手机/紧凑布局重排，超宽屏保留更多横向背景。程序化图形重新绘制，文字纹理随放大提高精度。窗口重排保留当前对局。

运行 `bun 测试/浏览器/分辨率适配.ts` 直接验收当前 `产物/`（无需开发服务），覆盖320像素窄屏、手机高像素比、短横屏、1080p、2K、4K与超宽屏的菜单、设置滚动、成就、暂停设置和对局重排，截图和结果存入 `reports/resolution/`。设备像素比为浏览器模拟，不能代替手机真机或性能验收。

- 规则/状态机/纯函数：`测试/*.test.ts`（如 `玩法.test.ts`、`暂存技巧.test.ts`、`消行事件.test.ts`、`成就.test.ts`、`纪录.test.ts`），用 `bun test`。
- 实机脚本：`测试/*验收.ts`、`测试/视觉快照.ts`，用 Playwright 跑真实页面检查点击、视口、截图与发声，不使用 `*.test.ts` 后缀。
- 旅行商店和地域外观：`bun 测试/浏览器/旅行版.ts`，直接读取正式发布包，覆盖购买/穿戴/保存、真实成就与对局奖励、12套皮肤；`bun 测试/浏览器/旅行音频.ts` 对12首音乐和192项音效做Web Audio采样，输出在 `reports/travel/`、`reports/travel-audio/`。
- 视觉与状态机产物目录不提交；实际发声与节流由 `测试/落块体验验收.ts` 采集音效样本验证。

几何或截图采集只代表界面/发声层面的结果，不代表完整玩法验收；业务验收仍需实际的规则与交互检查。

设置中的音乐、音效与背景音效用滑块调节；背景音效默认关闭。商店纯享入口位于套件面板上方，退出位于屏幕底部，方块陈列使用地点主题底板。

货币以金色 O 形四格方块呈现，称为方块币；沿用原存档字段与余额。设置外观卡可直接横拖，竖拖滚动页面；背景音效使用独立氛围输出，音乐、交互音效和氛围分别调节。

音乐滑块会同步保存启用状态，首次与恢复默认均为0；菜单和对局登记当前曲目，调高音量即可播放。一次触屏拖动在确定方向后只归一个滚动区域，横拖穿过相邻外观行也不会带动它们。
