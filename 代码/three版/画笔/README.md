# Three 共享配方画笔

`index.ts`把游戏`组件/绘制/`的图形、文字与资源指令写入GM图元合批；颜色、布局和文字样式继续由共享配方提供。

`文字服务.ts`以字体、字号、字重和光栅像素比缓存图集。字形光栅倍率对齐Phaser文字最低分辨率2（`Phaser框架/界面/文字清晰度.ts`）：画布DPR1时也按2x光栅，画布DPR≥2时与画布同倍率；DPR1的2x字形额外把位图宽高与图集页内位置对齐到2纹理像素（`对齐像素`），降到1x画布时图元正好覆盖整数设备像素。合批四边形写入前把坐标对齐到画布设备像素网格（等价Phaser文字的`vertexRoundMode=full`），半像素偏移会造成整行灰边、细笔画被削掉。所有倍率都从256页开始只烘焙实际出现的字符，满页倍增到512/1024/2048并保留已见字符；DPR1不再预烘焙整份中文超集（2x光栅下会多占约三倍显存）。基础64页只提供纯色白块，保持1倍即可。

启动层按设备DPR和`代码/性能/画质.ts`的上限传入像素比，两档画质均保留最高4倍精度。每次清空合批后调用`开始帧()`；提交并渲染之后调用`结束帧()`。扩容与倍率切换保留旧页直到提交结束，避免本帧已写入的UV引用失效。总文字预算默认28MB，在32MB渲染纹理预算里给静态资源和扩容留出空间；不足时仅淘汰本帧未使用的图集，仍不足则明确报错。移除回调同时清除合批纹理索引与渲染预算，避免缓存引用积累。

相关规则验证：`bun test 测试/three版画笔.test.ts`。实际DPR、画布物理尺寸、图集页尺寸与纹理峰值由测试桥读取，模拟视口验收证据放`reports/视觉返工/`。
