# 代码导航

| 位置 | 职责 |
| --- | --- |
| `应用/启动.ts` | 组装框架、项目服务、资源、导航与页面；唯一游戏运行入口 |
| `应用/页面/`、`应用/对局/`、`应用/结算/` | 页面组合与玩法接入 |
| `玩法/` | 棋盘、旋转、随机、计分、模式状态机与对局编号；不依赖Three或GM工具 |
| `项目配置/` | 读取玩法配置表与组合旅行价格/奖励等项目规则 |
| `框架配置/` | 注入框架的主题、曲谱、音效、旅行接入表 |
| `设置/` | 项目玩家偏好、默认值及对共享设置的接入 |
| `语言/` | 双语字典及共享文案合并入口 |
| `视觉/`、`界面/` | 布局计算、绘制配方、业务界面数据；底层控件复用框架 |
| `视觉/外观/` | 方块、背景、界面语义主题与游戏外观参数/读取 |
| `存档/`、`成就/` | 项目存档字段、迁移及进度，复用框架存储 |
| `平台/` | 游戏的TapTap身份、榜单、云档与计分接入 |
| `性能/` | 项目画质与省电策略 |
| `音频/` | 项目结算音效接入；应用音频模块组装共享音频 |

测试桥、固定棋盘样本与主题预览接入统一在项目 `测试/接入/`，规则测试和性能/功能浏览器流程都在同一测试目录。发布构建通过常量裁剪接入，业务不读取测试目录数据。

框架源码在GM的`游戏模块库/框架/`，项目的框架是目录联接，rg默认不穿透。业务不导入GM工具、Node/Bun或独立预览入口。游戏自己的资源适配在应用资源模块，Three引擎实现集中在框架及这一明确适配边界。

配置运行值见[配置导航](../配置/README.md)。不新建另一份“通用/工具/配置”抽屉，不为文件行数拆模块，不保留迁移旧路径的转发文件。

`界面/页面过渡.ts` 为菜单、模式选择和纯享提供双向分组过渡：先移出0.22秒，再移入0.22秒；文字、图形和裁剪同步移动，两阶段均停用热区，全部结束后恢复。主菜单与商店分别持有自己的目标状态。

列表统一使用框架 `列表`：成就底板、图标与文字共用默认居中的项矩形；商店和设置无需选择普通/虚拟实现。框架按真实尺寸、离屏子控件工作量及连续CPU开销自适应，业务状态仍由页面保存。验收：`bun 测试/浏览器/自适应列表.ts http://127.0.0.1:3001`。

模式选择入场由 `组件/霓虹街机/入场演出.ts` 的 `入场参数` 集中管理时间、曲线、运动幅度、模式染色和分组落位。模式页1.06秒错峰聚焦、加速压线和短凝聚，对局页1.34秒快速释放、减速落位与READY/GO，合计2.4秒；收束和释放采用不同曲线，文字、图标与边框随整卡收束到后段才消融；幕布终点取卡片实时边界，亮度集中于接缝窄带。凝聚峰值在闭合瞬间出现，余辉连续传给展开首帧。棋盘、网格、顶栏、侧栏和操作盘沿既有绘制入口错峰显现；READY在最后落位前0.16秒开始，落位后恢复正式像素坐标，不保留变形。演出期间不计时、不接受落块；暂停和失焦事件冻结进度，重开只播放0.90秒短节拍，不重播界面分组位移。

规则测试：`bun test 测试/入场演出.test.ts`。真实Chrome验收及录像：`bun 测试/浏览器/入场演出.ts http://127.0.0.1:3001`（390×844），额外手机比例用 `--宽=430 --高=740 --仅模式`，省电帧率用 `--省电`；结果位于 `reports/入场精修/`，模拟视口不是手机真机。

设置、成就、商店的打开与返回由 `界面/页面开合.ts` 集中配置：打开0.30秒快速展开后减速落位，关闭0.20秒加速收回。启动层通过框架 `图元合批.设置层变换` 变换缓存图层，文字、图标和面板一起运动，背景风景仅淡入淡出；不逐帧重建页面。收回后才执行导航，动画期间关闭命中并隔离按键；最终移除变换，恢复原布局与交互。规则验收：`bun test 测试/页面开合.test.ts`；浏览器预览：`bun 测试/浏览器/页面开合.ts http://127.0.0.1:3001`。
