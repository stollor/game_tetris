# 代码导航

按职责找文件，不按引擎版本或视觉风格。

`代码/` 只放代码；根目录 `预制体/视效/主题/资源/宣发` 是资源一级目录，与 GM 看板 6 个资源 Tab 同构，页面不进入资源目录。本页表格里对照资源时给出根目录路径。

| 要改什么 | 位置 |
| --- | --- |
| 按钮、面板、图标、卡片、棋盘等视觉对象 | [项目预制体](../预制体/README.md)：预制体/基础、模式选择、对局、收藏、外观、结算 |
| 完整页面、数据读取、点击动作与导航 | [页面](页面/README.md)：代码/页面/；布局集中在代码/页面/布局/ |
| 基础、旅行、模式和收藏的颜色 | [主题](../主题/README.md)：根目录 主题/，配色在 主题/配色/ |
| 字体、字号、文字样式 | 主题/文字/ |
| 方块质感、背景选择、外观规格 | 主题/外观/ |
| 背景、动画特效与页面转场 | [视效](../视效/README.md)：根目录 视效/，分背景、特效、过渡、透视 |
| 模式文案、仪表数据、列表与风景浏览 | [界面接入](界面/README.md)：代码/界面/ |
| 棋盘、旋转、随机、计分与模式状态机 | 代码/玩法/；不依赖 Three 或 GM 工具 |
| 玩法参数、定价、奖励 | [项目配置](项目配置/README.md)：读取配置/配置表.json |
| 框架音乐、音效、地域视听与翻译接入 | [框架配置](框架配置/README.md)：代码/框架配置/ |
| 玩家偏好、持久化与进度 | 代码/设置/、代码/存档/、代码/成就/ |
| 双语文案 | 代码/语言/；文案.ts 合并框架通用文案与游戏字典 |
| 平台身份、排行榜、云存档 | 代码/平台/ |
| 音频播放与画质策略 | 代码/音频/、代码/性能/ |
| 启动、服务组装、资源加载与页面协议 | 代码/应用/；入口为启动.ts |

新增内容按职责归位：纯绘制进入预制体，读取玩法和存档的界面内容进入页面或界面接入；不能因为名称带“配方”就全部放进预制体。参数与绘制分开维护，游戏和 GM 预览引用同一份源码。

index.html 只承载 Canvas 并加载代码/应用/启动.ts。390×844 是逻辑设计基准，控件与文字由共享框架适配。框架源码经根目录框架/联接使用，不复制到项目。

构建与开发命令在运行/；测试桥、固定样本与主题预览通信在测试/接入/，发布构建裁剪测试接入。资源独立预览适配在预制体/预览/。配置入口见[配置导航](../配置/README.md)。
