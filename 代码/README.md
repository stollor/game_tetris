# 代码导航

| 位置 | 职责 |
| --- | --- |
| `应用/启动.ts` | 组装框架、项目服务、资源、导航与页面；唯一游戏运行入口 |
| `应用/页面/`、`应用/对局/`、`应用/结算/` | 页面组合与玩法接入 |
| `玩法/` | 棋盘、旋转、随机、计分、模式状态机与对局编号；不依赖Three或GM工具 |
| `项目配置/` | 读取玩法配置表与组合旅行价格/奖励等项目规则 |
| `框架配置/` | 注入框架的主题、曲谱、音效、旅行接入表 |
| `设置/` | 项目玩家偏好、默认值及对共享设置的接入 |
| `语言/` | 双语字典及共享文案合并入口 |
| `视觉/`、`界面/` | 布局计算、绘制配方、业务界面数据；底层控件复用框架 |
| `视觉/外观/` | 方块、背景、界面语义主题与游戏外观参数/读取 |
| `存档/`、`成就/` | 项目存档字段、迁移及进度，复用框架存储 |
| `平台/` | 游戏的TapTap身份、榜单、云档与计分接入 |
| `性能/` | 项目画质与省电策略 |
| `音频/` | 项目结算音效接入；应用音频模块组装共享音频 |

测试桥、固定棋盘样本与主题预览接入统一在项目 `测试/接入/`，规则测试和性能/功能浏览器流程都在同一测试目录。发布构建通过常量裁剪接入，业务不读取测试目录数据。

框架源码在GM的`游戏模块库/框架/`，项目的框架是目录联接，rg默认不穿透。业务不导入GM工具、Node/Bun或独立预览入口。游戏自己的资源适配在应用资源模块，Three引擎实现集中在框架及这一明确适配边界。

配置运行值见[配置导航](../配置/README.md)。不新建另一份“通用/工具/配置”抽屉，不为文件行数拆模块，不保留迁移旧路径的转发文件。
