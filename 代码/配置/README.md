# 游戏参数配置

`游戏外观.ts` 是俄罗斯方块的可调外观入口，集中维护模式卡片内容、方块调色板、字体规格、按钮色板、棋盘透明度与关键布局尺寸。各个场景和预制体读取这份数据，不再各自维护同一组模式颜色或方块颜色。

`背景主题.ts` 维护可选背景的标签、说明、动画速度和亮度。背景的程序化绘制仍在 `代码/视觉/霓虹背景.ts`；添加背景时，在设置类型中加入选项、在这里添加参数，再给静态/动态绘制器增加对应实现。设置页下拉菜单和选项文案由主题配置生成。

## 调整外观

`代码/框架配置/界面主题.ts` 维护三套项目语义配方：夜空金紫、古典红金、未来青蓝。`界面主题.ts` 负责加载注册并读取当前主题，GM 预览和实际游戏共用；框架默认表不修改。

`方块外观.ts` 维护默认宝石、柔瓷、铬金、像素四套七色表及质感、辉光强度。实际笔触统一在 `组件/霓虹街机/方块单元.ts`；游戏设置的 `方块外观` 独立于界面主题保存，缺失或非法旧值回退默认。`游戏外观.方块.颜色` 动态读取所选方案，棋盘、预告、暂存、菜单演示与特效共用；缓存签名同时包含方案颜色。GM 的预览覆盖只在当前预览页面生效，不写入玩家设置。

- 修改字号：调整 `游戏外观.字体` 中对应用途的值。
- 修改按钮：调整 `游戏外观.按钮` 或其“主要 / 次要 / 普通”变体。
- 调整方块配色与材质：调整 `方块外观.ts` 的方案表及 `组件/霓虹街机/方块单元.ts` 的对应笔触；预览卡片规格在 `游戏外观.方块`。
- 调整棋盘透明度和顶栏尺寸：调整 `游戏外观.棋盘`、`游戏外观.布局`。
- 修改一个游戏模式的标题、说明或强调色：修改 `游戏外观.模式` 中该模式实例的数据。

模式的玩法规则仍由 `代码/玩法/俄罗斯方块.ts` 管理；外观配置只描述显示和规格，避免视觉修改改变游戏规则。模式目标、锁定节奏与下落速度等运行参数不在本目录，见 `配置/配置表.json` 与 `代码/项目配置/`。
