# 界面接入

这里把玩法、纪录、主题与语言组合成页面需要的显示数据，不承担完整页面或基础控件绘制。

| 文件 | 职责 |
| --- | --- |
| 代码/界面/模式卡数据.ts | 模式标题、说明、目标与纪录行装配 |
| 代码/界面/对局仪表.ts | 根据模式和布局计算仪表数据 |
| 代码/界面/技巧反馈.ts | 将真实落块事件转成技巧提示 |
| 代码/界面/目录滚动.ts | 目录滚动与选中位置 |
| 代码/界面/风景浏览.ts | 风景列表与相邻项选择 |

完整页面在代码/页面/，纯绘制在预制体/，颜色与文字在主题/，页面入场与开合在视效/过渡/。直接导入实际实现，不增加转发入口。
