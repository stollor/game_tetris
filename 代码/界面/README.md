# 游戏界面接入

这里是再消一行对 `组件/霓虹街机` 的接入：把纯视觉配方接到玩法数据、文案、设置和回调上。场景只负责玩法内容与装配，具体配色与结构来自组件。

| 文件 | 做什么 |
| --- | --- |
| `按钮.ts` | 霓虹按钮接菜单开始音效与音频解锁 |
| `模式卡.ts` | 读 `游戏外观.模式`、历史最佳和开始回调，生成模式选择卡 |
| `对局顶栏.ts` | 按文案生成等级/分数/消行信息栏和模式提示文字 |
| `操作说明卡.ts` | 按文案和「180° 旋转」设置生成操作说明卡 |
| `对局侧栏.ts` | 侧栏底板与最佳纪录页脚的接入（转发组件实现） |
| [结算页面](../应用/结算/结算页面.ts) | 编排方块结算、一次性飘字与重开/返回；视觉来自项目组件，输入复用框架按钮 |
| `方块单元.ts` | 转发 `组件/霓虹街机/方块单元` 的单元绘制 |
| `外观卡.ts` | 转发 `组件/霓虹街机/外观卡` 的设置页外观卡 |
| `风景浏览.ts` | 可浏览风景列表与左右相邻项，不依赖 Phaser |
| `纯享风景.ts` | 全屏看风景：返回在右下角（无关闭图标），点位与左右滑动；菜单与商店共用 |
| `金币条.ts` | 左上角带底板的金币显示，菜单、商店和成就共用，避开右上角平台按钮 |
| `主界面流转.ts` | 主界面各状态的流转身份和占位。同名内容交给框架位移或变形，不在页面里各写一遍出现和消失 |

玩法状态、输入、计时、特效编排和存档仍留在 `代码/场景/` 与 `代码/玩法/`；例如结算统计的取值、目标达成判定、暂停逻辑都在场景里，组件只负责显示。
