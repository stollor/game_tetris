# 项目配置

这里把 `配置/配置表.json` 的运行值读出来，组装成玩法直接引用的常量。表是数据，组合是入口：

- `模式.ts`：读取 `play-rules` 表，校验表编号后导出 `模式配置`（模式目标与结束条件）、`节奏配置`（锁定延迟与重置上限）、`速度表`（逐档下落速度）。
- 玩法代码（`代码/玩法/俄罗斯方块.ts`）只引用这些常量，不再各写硬编码数值。
- 新增运行参数先加进 `配置/配置表.json` 的字段与值，再在这里读取；改变量的默认值不写两份。
- 玩法专属规则（计分、旋转、随机、每日种子算法）留在 `代码/玩法/`，不放进配置表。

`旅行皮肤.ts` 保存部位定价、套装折扣和金币奖励配置，由 `存档/旅行收藏.ts` 消费。地域视觉参数、方块配色与纹样、原创曲谱接入值放在 `代码/框架配置/旅行地点.ts`，游戏与 GM 预览共用，不在文档复制另一份运行表。
