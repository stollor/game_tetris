# 视效（视觉特效）

这里组织跨页面的背景和随时间变化的表现，复用框架画笔、图元合批与控件。玩法计分、发奖和存档仍由对应业务负责。

| 目录 | 内容 |
| --- | --- |
| 代码/视效/背景/ | 背景绘制.ts 统一绘制静态与动态背景；内置主题、旅行风景、极光帘幕分文件实现 |
| 代码/视效/特效/ | 消行配方、对局特效状态、计分流光、结算演出与飞币 |
| 代码/视效/过渡/ | 模式入场、侧栏转场、主界面流转、页面双向过渡与开合 |
| 代码/视效/透视/ | 立体晶格对局井：前置渲染里的 3D 棋盘、灯光与 InstancedMesh 方块 |

颜色、字体和外观方案在代码/主题/；静态控件绘制在组件/；页面内容、命中和布局在代码/页面/。不在这里维护第二份页面或配色表。
