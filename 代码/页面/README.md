# 页面

完整页面集中在这里，负责读取服务、组合项目组件、绑定动作和导航。公共控件行为沿用框架。

页面只画自己的内容：**背景在背景层、货币在货币层、提示在提示层**，页面不再覆写背景绘制、不再画金币条、不再维护页内提示队列。页面的层归属与窗口策略由页面选项表达（`层`、`自带背景`、`不透明`、`暂停下层`、`独占命中`），没有「覆盖页」概念——暂停菜单与结算就是浮在对局上的普通页面。

窗口策略的默认口径：**页面层默认 `不透明: true`（同层后进的全屏页挡掉下面的页面），其它层默认 false**；`自带背景` 才会连带挡住背景层。所以菜单/模式选择/设置/成就/排行榜/对局都不需要自己铺底或声明自带背景；只有整页自己画风景或 3D 的页面（商店、透视对局，以及从商店进入的纯享）才声明 `自带背景`，而浮在对局上的暂停菜单与结算要显式 `不透明: false` 才看得见下面的对局。

**背景恒定**：菜单 / 模式选择 / 纯享三页都不画风景，背景只由背景层（远景页 + 近景页）提供，三页之间来回切背景像素不变；纯享只在「来源 = 商店」时按地点名画整屏风景（商店自带背景挡住了背景层，不画会露出清屏色）。

## 跨页流转

菜单页、模式选择页、纯享页各自实现 `读取流转块()`，声明这一页**全部可见元素**（身份 + 占位矩形 + 位移 + 绘制函数），公共助手在 `代码/页面/页面流转块.ts`：

| 身份 | 菜单页 | 模式选择页 | 纯享页 |
| --- | --- | --- | --- |
| `游戏标题` | ✓（大标题） | ✓（顶部小字） | — |
| `选择模式` | — | ✓（大标题 + 标题饰） | — |
| `模式:<模式名>` | — | ✓（每张模式卡，左右滑入） | — |
| `返回` | — | ✓（传送装置，向下滑出） | — |
| `开始游戏` | ✓（向下滑出） | — | — |
| `角钮:设置/成就/商店` | ✓（向左滑出） | — | — |
| `纯享` | — | — | ✓（整屏浮层，向上 160px 滑入） |

背景不进流转表：三页共用背景层那一张，过渡中本来就不变；只有 UI 元素参与身份衔接。

进入页面时若两页都有流转块，宿主进入跨页过渡（0.36s）：`规划界面流转` 算出这一帧每个身份的画面，页面在 `绘制过渡(环境)` 里遍历自己的块、取 `上下文.过渡.画面(页名, 身份)` 画到插值位置。两边都有的身份连续位移/变形（不淡入淡出），只有一侧的按贴边规则滑出或原地淡出。过渡期间页面只画流转块，启动层把该页控件/覆盖子层透明度置 0（旧几何不能叠上来）。

金币条在货币层，天然常驻，不参与流转。过渡只按「进入」触发：两侧都有流转块才起过渡，只有一侧有就直接切（例如商店→纯享，商店没有流转块）；「返回」是弹栈，框架不给退场动画。

玩法算法仍在代码/玩法/；控件绘制在组件/；颜色与文字在主题/；入场、结算演出与开合动画在视效/。应用启动、四层装配与渲染循环在代码/应用/启动.ts。

所有页面继承框架页面基类：框架自动管理每页控件层的创建、绑定、更新与释放，页面在构建时描述按钮、滑块、开关和列表。页面只按需重建自己的子层（内容/控件/覆盖；对局与框架层页面另有约定）。对局保留七层绘制与玩法输入状态机，操作键与 HUD 暂停键在对局页；暂停是页面层上不暂停下层的浮层页面（独占命中），设置壳体复用框架面板，点外关闭走弹窗同一套全屏关闭+面板拦截，网格/按键说明走开关。设置页布尔项（动态背景、显示按键说明）走框架开关，省电模式仍是三选一按钮。自绘配方保留现有外观；透明热区仅保留在交易遮罩与面板、纯享滑动等特殊区域。
