# 页面

完整页面集中在这里，负责读取服务、组合项目组件、绑定动作和导航。公共控件行为沿用框架。

| 位置 | 职责 |
| --- | --- |
| 代码/页面/主界面.ts | 主菜单、模式选择与纯享状态 |
| 代码/页面/商店界面.ts、商店定价.ts | 外观浏览、试穿、购买与价格显示 |
| 代码/页面/设置界面.ts | 游戏设置与语言选择 |
| 代码/页面/成就界面.ts、排行榜界面.ts | 成就进度与真实平台榜单 |
| 代码/页面/对局/ | 对局页面、输入、模式接入、棋盘/HUD 绘制与对局内设置 |
| 代码/页面/结算/ | 结算页面、结算数据装配与最近对局状态 |
| 代码/页面/布局/ | 主界面、商店、覆盖页和对局的布局计算 |
| 代码/页面/游戏页面基类.ts | 共用背景与生命周期接入 |
| 代码/页面/页面表.ts | 菜单类页面注册；启动层直接导入对局与结算实现 |

玩法算法仍在代码/玩法/；控件绘制在组件/；颜色与文字在代码/主题/；入场、结算演出与开合动画在代码/视效/。应用启动仍在代码/应用/启动.ts。
