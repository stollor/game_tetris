# 立体晶格

完整主题：棋盘与已落/当前/幽灵方块使用透视3D；菜单、HUD、操作键、暂存/预览和弹窗继续使用极光2D。主题编号为 `立体晶格`，棋盘表现与视觉特效为 `透视`，仪表为装置/灯条。

[立体规范](立体规范.ts)是唯一视觉参数源，正式游戏与GM资源预览共用[透视棋盘](../../视效/透视/README.md)。

| 参数组 | 调整内容 |
| --- | --- |
| 房间 | 既有投影占比、墙面底色、壁板厚度/缝隙/分段/折面与格线 |
| 装置 | 金属口沿、护角、壁肋、灯芯位置/尺寸/颜色及少量局部柔光 |
| 光 | 环境、主光与补光、侧壁和顶部真实面光源 |
| 镜头 | 保持正视的视野与裁剪范围 |
| 块 | 实体厚度、倒角、离墙间隙、粗糙度与清漆 |
| 幽灵 / 阴影 | 描边透明度、线宽与主光投影参数 |
| 方块 | 七种方块颜色，暂存和下一个共用同一色表 |

墙壁纵深来自实际分段几何、透视、材质受光与灯带照明。方块通过真实厚度、法线、倒角和投影呈现体积，物理材质负责表面反光。颜色遵循共享渲染器LinearSRGB直通约定。

验证入口、截图范围和资源释放说明见[透视棋盘](../../视效/透视/README.md)。本主题不改变玩法规则、购买或存档结构。
