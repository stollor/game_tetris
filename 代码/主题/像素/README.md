# 像素主题视觉规范

《再消一行》的像素完整换肤。真正的点阵绘制，不是给极光原野贴像素滤镜。数值只在 `像素规范.ts`，本文件说明为什么这样画。

两套完整主题共用网格、字体和硬边矩形，用配色与方块填法分开：

| 项 | 砖机液晶 | 街机彩砖 | 极光原野 |
| --- | --- | --- | --- |
| 底 | 浅液晶 `#9bbc0f` | 深蓝井 `#1a1c2c` | 深蓝 `#07142d` |
| 字 | 深绿墨 `#0f380f` | 奶油 `#f4efe4` | 浅青字 |
| 体积 | 无。1 格描边 | 无。深色壳描边 | 斜面、高光、柔影 |
| 方块 | 四色 + 七种点阵纹 | 七色实心 + 暗点纹理 | 七彩宝石 |
| HUD | 液晶窗 + 点阵数字 | 深色窗 + 奶油字 + 金强调 | 切角装置舱 |
| 动效 | 8 帧一步 | 8 帧一步 | 连续缓动 |
| 声 | 方波 96 BPM | 方波 120 BPM | 正弦霓虹 |

绘制期读 `当前像素规范()`（`像素规范` 是活代理）。配色表和方块外观方案必须引用 `砖机液晶规范` / `街机彩砖规范`，不能在模块加载时冻住活规范。

## 比例

- 网格 4 逻辑像素。坐标、描边、图标、扫描线都对齐网格。
- 描边 4。面板是外壳描边套井，没有投影。
- 外壳外框 8、内框 4：屏幕外一圈机壳，界面叠在井上。
- 字号取 8 的倍数；字体 Fusion Pixel，烘焙前必须 `准备像素字体`。

## 砖机液晶

只许四色出现在画面上。语义别名（纸/夜/黄/青…）全部指向它们。

| 角色 | 色 | 用途 |
| --- | --- | --- |
| 底 | `#9bbc0f` | 液晶关态、页面、井 |
| 亮 | `#8bac0f` | 中亮、选中键、扫描 |
| 暗 | `#306230` | 胶壳中层、弱字、按下 |
| 墨 | `#0f380f` | 开态像素、正文、框 |
| 壳 | 同墨 | 掌机胶壳 |

七种方块共用四色，用点阵纹样区分；`方块填井` 为真：墨边 + 底井 + 色纹。

## 街机彩砖

深色井、奶油正文、金色强调。方块七色与极光宝石色值不同，靠色相识别，暗点只做纹理。`方块填井` 为假：壳边 + 实心色 + 壳纹。HUD 对比按正文 ≥ 4.5。

| 角色 | 色 | 用途 |
| --- | --- | --- |
| 底 / 夜 | `#1a1c2c` / `#12141f` | 页面、棋盘井 |
| 纸 | `#243044` | 面板 |
| 墨 | `#f4efe4` | 正文、图标 |
| 次字 | `#8b9bb4` | 弱化 |
| 亮 | `#ffd37a` | 强调、选中键 |
| 壳 | `#0e1220` | 机壳、方块描边 |

## 组件

- **棋盘**：壳框、井、暗色角扣。网格是暗点，不是发光线。
- **方块**：见上。幽灵只画四角点。不要斜面高光。
- **HUD**：三个矩形窗，点阵标签与补零数字。进度是点，不是灯条。
- **按钮 / 弹窗 / 模式卡**：矩形键。按下改填暗色并下沉一格，不做缩放缓动。
- **图标**：9×9 点阵。
- **背景**：砖机液晶是壳 + 井，动态层只有步进扫描线；街机彩砖用专属街机机厅后景（点阵余晖、跑马灯、彩砖墙与扫描带），见 `代码/视效/背景/街机彩砖背景.ts`。不要星月云海。
- **特效**：消行/落块/庆祝只闪矩形点，8 帧一步。
- **音频**：方波短脉冲。曲谱走框架演奏，不堆包络。

## 替换入口

走已有主题契约，不平行建表。完整主题编号 `砖机液晶` / `街机彩砖`：

- 界面表现 / 字体 / 仪表表现 / 视觉特效 → `像素`
- 界面配色 / 控件外观 / 背景 / 方块 / 音效 / 音乐 → 各自主题名
- 仪表纹样 → `平涂`

未注册组件先补槽位再换皮。默认主题仍是极光原野。
