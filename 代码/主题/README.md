# 主题与外观

这里集中视觉参数。游戏页面、组件和 GM 预览直接引用这些文件。

| 位置 | 修改内容 |
| --- | --- |
| 代码/主题/配色/基础配色.ts | 三套完整基础语义配色，同时登记到框架 |
| 代码/主题/配色/旅行配色.ts | 从代码/框架配置/旅行地点.ts 派生旅行主题，不重复地点表 |
| 代码/主题/配色/模式配色.ts | 各模式强调色 |
| 代码/主题/配色/收藏配色.ts | 收藏纸面、墨色与金色 |
| 代码/主题/配色/主题读取.ts | 根据设置与预览选择读取语义主题 |
| 代码/主题/配色/调色板.ts | 将主题转换为组件使用的颜色角色 |
| 代码/主题/配色/控件配色.ts | 将游戏主题转换为框架控件颜色 |
| 代码/主题/文字/ | 文字样式、控件字号档位与覆盖页文字 |
| 代码/主题/外观/ | 游戏整体视觉规格、方块方案和背景参数 |
| 代码/主题/游戏主题.ts | 从玩家设置生成页面共用主题 |
| 代码/主题/主题服务.ts | 监听设置与预览选择，通知页面刷新 |
| 代码/主题/背景外观.ts | 从背景读取主色、强调色与文字基调 |

方块、旅行纹样和外观卡的实际绘制在组件/；背景绘制在代码/视效/背景/。玩家选择的主题仍保存在既有设置与存档中。
