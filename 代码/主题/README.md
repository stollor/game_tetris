# 主题与外观

这里集中视觉参数。游戏页面、组件和 GM 预览直接引用这些文件。

| 位置 | 修改内容 |
| --- | --- |
| 代码/主题/配色/基础配色.ts | 三套完整基础语义配色，同时登记到框架 |
| 代码/主题/配色/旅行配色.ts | 从代码/框架配置/旅行地点.ts 派生旅行主题，不重复地点表 |
| 代码/主题/配色/模式配色.ts | 各模式强调色 |
| 代码/主题/配色/收藏配色.ts | 收藏纸面、墨色与金色 |
| 代码/主题/配色/主题读取.ts | 根据设置与预览选择读取语义主题 |
| 代码/主题/配色/调色板.ts | 将主题转换为组件使用的颜色角色 |
| 代码/主题/配色/控件配色.ts | 将游戏主题转换为框架控件颜色 |
| 代码/主题/文字/ | 文字样式、控件字号档位与覆盖页文字 |
| 代码/主题/外观/ | 游戏整体视觉规格、方块方案和背景参数 |
| 代码/主题/游戏主题.ts | 从玩家设置生成页面共用主题 |
| 代码/主题/主题服务.ts | 监听设置与预览选择，通知页面刷新 |
| 代码/主题/主题组合.ts | 从真实配置派生槽位与方案，解析旧设置与整套主题，供正式游戏及GM共用 |
| 代码/主题/背景外观.ts | 从背景读取主色、强调色与文字基调 |

方块、旅行纹样和外观卡的实际绘制在组件/；背景绘制在代码/视效/背景/。玩家选择的主题仍保存在既有设置与存档中。

主题组合直接读取基础配色、基础背景、方块方案、旅行地点和旧默认设置。12套完整旅行主题、3套配色、4套背景及4种独立方块外观按身份区分，不复制颜色或曲谱表。八个槽位覆盖静/动态背景、界面配色、控件参数、方块、特效、音效与音乐；旅行套装继承现有特效，当前不提供另一套绘制实现。

解析顺序是局部指定→方案覆盖→游戏默认。`穿戴旅行外观`的整套应用调用同一解析器，仍先校验所有权；局部穿戴继续原逻辑。已有设置字段作为局部选择读取，不新增存档字段。应用设置服务、主题服务与页面读取同一有效结果；设置、成就与排行榜明确读取旅行配色，预览上下文不覆盖正式玩家设置。

GM独立页面通过`组件/预览/主题状态.ts`传入方案，由正式主题服务和绘制接线；可显式开启正式音频服务试听，默认关闭，切换/销毁时释放。商店商品试穿、模式识别色及收藏纸面保留自身设计语义。规则：`bun test 测试/主题组合.test.ts 测试/界面主题.test.ts 测试/旅行收藏.test.ts 测试/页面预览环境.test.ts`；真实页面、发声与刷新验证在GM的`测试/浏览器/看板/主题资源闭环.ts`，完整玩法回归继续`测试/浏览器/three版验收.ts`。
