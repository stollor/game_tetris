# 代码/视觉

游戏专属视觉配方：背景风景、落块/消行特效、菜单演示与图像缓存优化。
框架通用控件不在这里（见 `框架/`）；主界面 UI 配方在 `组件/霓虹街机/`。

## 单一来源：背景绘制分三层

背景的构图、色值、数值只有一份，Phaser 与 Three 都走它：

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 纯配方（引擎无关） | `背景配方.ts`、`背景配方/{通用,内置主题,旅行风景,极光帘幕}.ts` | 只依赖 `组件/绘制/图形对象.ts` 契约与共享配置，导出冻结入口 `绘制背景(绘图, {宽,高,主题,动态,时间秒})`；内置四主题 + 12 套旅行地点，静态与动态一次画全 |
| Phaser 委托 | `霓虹背景.ts`、`旅行风景.ts`、`极光演出.ts` | 保留原有导出名/签名/性能行为，内部只转调纯配方 |
| Three 消费 | `代码/three版/页面/` 用 `画笔.图形` 调用 `绘制背景` | 不再另画简化背景，也不新建色表 |

规则：

- 新增/修改背景视觉，先改纯配方，再让两版消费；不要在 Phaser 或 Three 侧重画同一画面。
- 纯配方不得 `import` Phaser、`框架Three`、场景/设置/存档；颜色、尺寸、文案全部来自参数或共享配置
  （`代码/配置/背景主题.ts`、`代码/框架配置/旅行地点.ts`、`代码/框架配置/旅行主题.ts`）。
- 纯配方的时间参数单位是秒；Phaser 传毫秒的旧入口由委托层换算。
- Phaser 专有优化不进纯配方：`图像池`/`风景缩略` 的 RenderTexture 烘焙、
  `霓虹背景`/`极光演出` 里的云朵与极光帘幕替身烘焙、动态层性能门控与图层 alpha 仍留在 Phaser 文件。
- `图像池.ts` 只有池与纹理绑定逻辑，画什么由调用方传入的绘制回调决定。
- `风景缩略.ts` 烘焙缩略图与整屏底图，绘制经 `绘制霓虹背景` 走同一套纯配方。
- `菜单演示.ts` 用真实规则驱动自动对局；`技巧反馈`、`消行特效`、`落块特效` 是玩法表现。

## 对局与结算

- `对局布局.ts` 是三档视口的棋盘、侧栏、触屏、暂停与桌面附属布局来源；Three 的特效使用同一棋盘原点与格子尺寸，resize 时同时更新绘制与命中。
- `对局设置配方.ts` 按 Phaser `代码/预制体/对局设置菜单.ts` 的面板与控件几何提供纯绘制，Three 的暂停内设置保留对局，不切到全局设置页。
- `特效配方.ts` 的时间参数保持原毫秒语义；成就提示透明度入口接收秒，在最后350毫秒淡出。Three 暂停时冻结提示与特效计时。
- `结算金币配方.ts` 复用 Phaser 结算面板的计数延迟、飞币、放射闪光与省电淡入；数字脉冲使用 `文字项.缩放`，字体字号固定，避免动画每帧新建字形图集。
- Three 本机测试桥 `准备四行消除()` 只准备真正四行缺口，随后 `硬降()` 仍执行真实玩法事件；`读取特效()` 与对局/结算快照提供动画状态用于连续帧验收。

- `测试/背景配方.test.ts`：16 主题 × 静态/动态的指令序列烟测、亮度参数、确定性与「纯配方不 import Phaser」约束。
- `测试/风景缩略.test.ts`：Phaser 烘焙/缓存策略。
- `测试/three版特效.test.ts`：出生硬降拖尾、真实单行/四行事件、成就淡出单位、金币动画/省电降级及对局内设置几何。
