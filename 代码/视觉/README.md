# 代码/视觉

游戏专属视觉配方：背景风景、落块/消行特效、菜单演示与图像缓存优化。
框架通用控件不在这里（见 `框架/`）；主界面 UI 配方在 `组件/霓虹街机/`。

## 单一来源：背景绘制分三层

背景的构图、色值、数值只有一份，Phaser 与 Three 都走它：

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 纯配方（引擎无关） | `背景配方.ts`、`背景配方/{通用,内置主题,旅行风景,极光帘幕}.ts` | 只依赖 `框架/界面/绘制/协议.ts` 契约与共享配置，导出冻结入口 `绘制背景(绘图, {宽,高,主题,动态,时间秒})`；内置四主题 + 12 套旅行地点，静态与动态一次画全 |
| Phaser 委托 | `霓虹背景.ts`、`旅行风景.ts`、`极光演出.ts` | 保留原有导出名/签名/性能行为，内部只转调纯配方 |
| Three 消费 | `代码/应用/页面/` 用 `画笔.图形` 调用 `绘制背景` | 不再另画简化背景，也不新建色表 |

规则：

- 新增/修改背景视觉，先改纯配方，再让两版消费；不要在 Phaser 或 Three 侧重画同一画面。
- 纯配方只从 `框架/界面/绘制/协议.ts` 导入绘制类型，不得导入 Phaser、Three 框架运行时或场景/设置/存档；颜色、尺寸、文案全部来自参数或共享配置
  （`代码/视觉/外观/背景主题.ts`、`代码/框架配置/旅行地点.ts`、`代码/框架配置/旅行主题.ts`）。
- 纯配方的时间参数单位是秒；Phaser 传毫秒的旧入口由委托层换算。
- Phaser 专有优化不进纯配方：`图像池`/`风景缩略` 的 RenderTexture 烘焙、
  `霓虹背景`/`极光演出` 里的云朵与极光帘幕替身烘焙、动态层性能门控与图层 alpha 仍留在 Phaser 文件。
- `图像池.ts` 只有池与纹理绑定逻辑，画什么由调用方传入的绘制回调决定。
- `风景缩略.ts` 烘焙缩略图与整屏底图，绘制经 `绘制霓虹背景` 走同一套纯配方。
- `菜单演示.ts` 用真实规则驱动自动对局；`技巧反馈`、`消行特效`、`落块特效` 是玩法表现。

## 对局与结算

- `对局布局.ts` 是三档视口的棋盘、侧栏、触屏、暂停与桌面附属布局来源；Three 的特效使用同一棋盘原点与格子尺寸，resize 时同时更新绘制与命中。
- `对局设置配方.ts` 按 Phaser `代码/预制体/对局设置菜单.ts` 的面板与控件几何提供纯绘制，Three 的暂停内设置保留对局，不切到全局设置页。
- `特效配方.ts` 的时间参数保持原毫秒语义；成就提示透明度入口接收秒，在最后350毫秒淡出。Three 暂停时冻结提示与特效计时。
- `结算金币配方.ts` 复用 Phaser 结算面板的计数延迟、飞币、放射闪光与省电淡入；数字脉冲使用 `文字项.缩放`，字体字号固定，避免动画每帧新建字形图集。
- Three 本机测试桥 `准备四行消除()` 只准备真正四行缺口，随后 `硬降()` 仍执行真实玩法事件；`读取特效()` 与对局/结算快照提供动画状态用于连续帧验收。

## 覆盖页（设置/成就/排行榜）

Phaser 版这三页是覆盖在 `开始菜单` 上的独立场景，几何/文字/按钮各自写在场景里。为避免 Three 页再抄一份表，逐项抽到这里：

| 文件 | 职责 |
| --- | --- |
| `覆盖页布局.ts` | 纯几何：成就列表 `min(680,w-32)` 居中（行高 94、板高 84、说明宽/数量 x/返回按钮）、排行榜标题/周期页签/我的状态/榜单列表/底部按钮行。数值与 Phaser 场景逐条一致 |
| `覆盖页按钮配方.ts` | 这三页 Phaser 用的是框架通用 `界面按钮`（不是霓虹变体）：已选取主题 `按钮.主要.点击`、未选取 `按钮.次要.默认`，面板/边框透明度用框架默认 0.92/0.55；Three 页拿它喂 `组件/霓虹街机/按钮配方.绘制霓虹按钮` 的覆盖参数 |
| `覆盖页文字.ts` | Phaser `scene.add.text` 未写 `fontFamily` 时默认族是 `Courier`（ASCII/数字/空格等宽），与霓虹文字栈不同；只给覆盖页的原生标题/副题/列表行/状态使用 |
| `覆盖页面板.ts` | 复刻 Phaser `Rectangle` 的 1px 描边与 1px 分隔线在画布像素比 1 时的半透明分摊（≥2 时为实色单像素），用于设置页中央面板与分组分隔线 |

约束：

- 只有 `代码/应用/页面/` 消费这些配方；Phaser 场景保持原实现（画面是真相，不得为抽取改动）。
- `覆盖页文字.ts` 的 Courier 只用于覆盖页的原生文字，主界面/对局等页面不要直接套用；其它页要逐像素对齐时按各自 Phaser 文字的 `fontFamily` 判断。
- 改 `覆盖页布局.ts` 的数值等于同时改两版的对齐基准，必须重跑 `测试/浏览器/桌面复刻验收.ts`。


## 测试

- `测试/背景配方.test.ts`：16 主题 × 静态/动态的指令序列烟测、亮度参数、确定性与「纯配方不 import Phaser」约束。
- `测试/风景缩略.test.ts`：Phaser 烘焙/缓存策略。
- `测试/three版特效.test.ts`：出生硬降拖尾、真实单行/四行事件、成就淡出单位、金币动画/省电降级及对局内设置几何。
