# 框架配置

这里只放“调用 GameMaker 框架时要填的表”。改这些表只改变接入方式与表现，不改玩法结算。

| 文件 | 对应框架能力 | 调用方式 |
| --- | --- | --- |
| `旅行地点.ts` | 地域视听接入值 | 12个地点的背景、纹样、材质、配色和原创音乐参数，游戏与组件预览共用 |
| `界面主题.ts` | `框架/样式/样式` 的 `配置游戏主题` | 游戏与预览经 `代码/配置/界面主题.ts` 加载，共用三套基础语义主题与12套旅行主题，框架默认配方保持原样 |
| `旅行主题.ts` | 语义主题 | 根据地点表生成12套主题，穿戴时通过既有 `配置游戏主题` 同步框架控件 |
| `旅行音效.ts` | 合成音效谱 | 为每个地点生成完整16项音效，保留基础节奏并使用不同音色、频率和包络 |
| `音乐.ts` | `框架/音频/音乐目录`、`音乐编排` 的 `曲谱` | `代码/音频/再消一行程序音频.ts` 里 `注册音乐库(音乐库)`；商店选地点即 `试听旅行音乐`，菜单和对局默认不播曲 |
| `场景氛围.ts` | 环境声循环配方 | 16处风景的风、雨、水、沙等；`播放场景氛围` 走独立氛围输出 |
| `音效.ts` | `框架/音频/音效目录`、`音效编排` 的 `合成谱` | 同模块 `注册音效库(音效库)` 统一登记，`注册程序音效` 覆盖消行/连击的动态参数 |

## 需求 → 接入表 → 调用方式

- **背景音乐**：曲谱仍登记，但菜单和对局默认关闭（音乐0%）；调高音乐滑块即开启对应曲目，归零停止，商店按同一音量试听18秒。12套旅行曲谱用不同主音、气质、和弦和气口，由框架 `演奏曲谱` 展开。
- **场景氛围**：每处风景循环风、雨、水、沙等环境声，由设置中的背景音效调节，默认0（关闭），使用独立输出，不受音乐或交互音效音量影响，不当成旋律。
- **操作与事件音效**：基础16种及12套地域音效登记在 `音效库`，合成谱字段与 `程序音频.ts` 对应。`消行`/`连击` 依赖消行数，注册表里放代表谱（消行数=1、消行数=3），播放时由游戏用 `消行谱`/`连击谱` 动态覆盖同名 id。
- **节流**：移动/软降 45ms、其余 25ms 的去重仍在游戏侧 `再消一行程序音频.ts`，不在表里。

## 语言与视觉配方

- 语言：`代码/语言/` 是游戏自己的文案字典，`代码/配置/再消一行文案.ts` 把框架通用文案与它们合并后再给场景用，已是可复用的接入方式，不再搬一次。
- 主题：本目录 `界面主题.ts` 登记夜空金紫、古典红金、未来青蓝三套游戏配方；`代码/配置/界面主题.ts` 读取注册后的语义主题，设置缩略卡、框架控件、棋盘、HUD 与预览一致。背景风景和方块质感独立选择。
- 框架接入表放这里，玩法数值放 `代码/项目配置/` 或 `配置/配置表.json`。

音乐滑块会同步保存启用状态，首次与恢复默认均为0；菜单和对局登记当前曲目，调高音量即可播放。一次触屏拖动在确定方向后只归一个滚动区域，横拖穿过相邻外观行也不会带动它们。
