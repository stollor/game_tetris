# 游戏预制体

Three 页面组合项目通用控件与游戏专属视觉配方。玩法状态、布局规则和页面导航由游戏代码负责；控件逻辑复用 `框架Three/界面/控件/`，游戏专属方块、棋盘和商店外观放在 `组件/`。

| 能力 | 归属 |
| --- | --- |
| 按钮、面板、滚动容器、页签、弹层、滑块、开关 | `框架Three/界面/控件/` |
| 棋盘格、活动块、投影与预览块 | `组件/霓虹街机/方块单元.ts` |
| 页面布局、旅行主题与玻璃绘制配方 | `组件/霓虹街机/`、`组件/旅行收藏/` |

新组合先使用 Three 框架已有控件，再由游戏页面注入文案、主题、位置和操作回调。不要为 Phaser 兼容保留第二套实现。
