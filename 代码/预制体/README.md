# 游戏预制体

场景负责把状态和响应式位置交给预制体，预制体负责自己的显示结构。跨游戏的 Phaser 界面预制体放在 `框架/组件/Phaser界面/`，俄罗斯方块独有的组合预制体放在本目录。

| 预制体 | 复用方式 |
| --- | --- |
| `框架/组件/Phaser界面/按钮.ts` | 首页、模式选择、对局操作、暂停和结算按钮复用同一类；尺寸、文案、按下/松开行为和色彩由实例参数决定。 |
| `框架/组件/Phaser界面/模式卡片.ts` | 四个游戏模式使用同一张卡片预制体，区别只在模式数据、强调色、位置和尺寸。 |
| `框架/组件/Phaser界面/数值面板.ts` | 对局顶部栏是一份预制体实例，内部指标数量、标题、数值和颜色由数据决定。 |
| `框架/组件/Phaser界面/暂停菜单.ts` | 暂停遮罩、面板与三个操作按钮作为一个组合预制体；按钮继续使用通用按钮预制体。 |
| `框架/组件/Phaser界面/触屏操作区.ts` | 六个操作符号是六个通用按钮实例，组合类只负责行列位置和输入事件转发。 |
| `俄罗斯方块棋盘.ts` | 游戏专属棋盘预制体负责框体、落地块、活动块和投影。 |
| `下一个方块栏.ts` | 游戏专属三格预览栏按方块序列渲染三张预览卡片。 |
| `框架/组件/Phaser界面/方块单元预制体.ts` | 所有棋盘格、活动块、投影和预览块复用统一的程序化单元绘制模板。大量活动单元由同一模板绘到图形层，避免为每个方块引入独立输入对象。 |

## 增加一个可复用界面

先在 `框架/组件/Phaser界面/` 增加一个有清楚尺寸/布局接口的 Phaser `Container`，实例配置只描述外观和回调；游戏规则、设置存储和多语言读取由所属场景完成。只有单个游戏特有的组合结构才放在 `代码/预制体/`。接入实际场景后再确认是否值得沉淀到 GameMaker 的共享模板。
