# 项目组件

这里保存《再消一行》独立维护的真实视觉配方。控件行为复用框架/界面/控件/，本目录负责外形、图案与绘制。棋盘、方块、HUD、暂存槽和模式卡是业务组件：输入为布局加玩法快照或模式数据，输出为纯绘制；分类为 `业务`，生命周期与事件走框架。页面只组装数据并调用。

| 目录 | 内容 |
| --- | --- |
| 组件/基础/ | 按钮、玻璃底板、面板、矢量图标、成就图标、金币条与列表页配方 |
| 组件/模式选择/ | 模式卡与模式装置 |
| 组件/对局/ | 棋盘、方块、HUD 仪表、暂存槽、操作键与侧栏 |
| 组件/收藏/ | 收藏牌面、收藏按钮与部位预览 |
| 组件/外观/ | 外观选择卡、旅行纹样、缩略预览与纯享控件 |
| 组件/结算/ | 结算台的静态视觉配方 |
| 组件/预览/ | GM 独立预览环境与样例状态，调用正式组件与整页绘制 |

配色统一在代码/主题/配色/，文字样式在代码/主题/文字/，方块质感与背景参数在代码/主题/外观/。完整页面和布局在代码/页面/，背景、特效与转场在代码/视效/。

霓虹街机是当前视觉风格，不再作为混放所有文件的目录。新增对象按用途归入上表；换皮修改主题或相应组件。

## 独立预览

`组件/预览/界面资源.ts`只登记真实视觉家族、样本与源码引用，分类由GM按第一源码的实际目录生成，不维护第二份分类表。基础控件、模式装置、对局构件、收藏与外观、颜色、背景及特效共用原样品协议。组合样品列出实际绘制的组成源码，GM再沿精确导出调用生成组合入口；静态关联不等于所有分支已运行通过。

`组件/预览/页面样品.ts`通过一张描述表调用主界面、对局、设置、成就、排行榜、商店与结算的真实页面类。`组件/预览/页面环境.ts`是这些页面唯一的只读业务环境：设置只改当前实例的内存，金币、奖励和成就写操作拒绝，导航不启动正式应用，平台不装配。主题状态从正式`代码/主题/主题组合.ts`派生，主题与背景调度复用正式服务和画质参数。音频默认静默，显式开启试听后装配正式音频服务，需用户手势解锁，切换与销毁时停止并关闭上下文。结算明细只在隔离窗口内提供固定视觉样本，展示金币与成就演出，不执行发奖。对局要求GM开发测试入口存在，标记不写存档后才显示；预览未开启该入口就报错。

GM场景宿主统一提供画笔、合批、输入、尺寸、图层缓存与销毁。项目只准备资源和上下文，不另建渲染器。独立入口先隔离存储，再动态导入生产模块；预览不会加载正式启动入口，不修改玩家设置与存档。排行榜显示当前环境的真实离线状态，不编造在线成绩。

消行光带、入场幕面、凝聚横线、开局节拍、页面过渡、落块拖尾、锁定闪光和四行庆祝复用框架`创建时间轴样品`。循环/定格与0–100%进度由框架提供；时长与姿态从正式配方读取，不再维护预览专属的动画节奏。背景等已有连续场景仍保留原状态接口。

`game-board`保留固定玩法样本的390×844整页视觉，模式、暂停、语言及绘制入口可切换；基础图元入口调用该模块的原有绘制，不代表玩家当前正式入口。`页面-对局`则调用真实页面实例，适合检查暂停和设置。音乐与250个音效沿用GM现有目录协议及通用试听器，不逐个编写适配。

验收入口：`bun test 测试/页面预览环境.test.ts`验证元数据惰性加载、实例隔离、只读服务和页面清理；GM看板实际预览与截图独立于完整游戏/真机验收。

`组件/预览/控件规格样品.ts`登记按钮、面板、弹层、列表项、角键、操作键与仪表的真实规格消费者；形状读`框架/样式/控件规格.ts`，颜色与主题仍走正式配方。`spec-meter`同时是主题组件独立预览，主源码精确指向`组件/对局/对局仪表.ts`的`绘制对局仪表`，保留控件规格元信息；其他规格样品以预览宿主为主入口。`bun test 测试/控件规格接线.test.ts`验证规格对真实绘制的影响。

仪表独立预览 `spec-meter` 使用 `资源主题`、`模式`（马拉松/冲刺/极限）与 `演示`（静止/计分反馈）。主题串可直接选 `极光原野@仪表表现=条带;仪表纹样=平涂`。表现与纹样直接来自完整解析；动画复用正式计分反馈与仪表动态绘制，不复制视觉实现。整体真实页面和规格样品共用完整主题读取，保留没有旧设置字段的替换，同时报告页面内实际修改的配色等设置。独立预览仍不表示正式游戏运行已验证；音乐与音效继续从整页显式试听。
旧按钮、模式卡、棋盘外框/网格、方块形状、背景样品通过 `组件/预览/主题状态.ts` 的 `接入资源主题` 使用正式主题上下文及真实槽位，继续调用原绘制配方；主题输入只存在于独立预览，不修改玩家设置。
