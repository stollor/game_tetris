# 项目 UI 组件

这里存放再消一行项目专属的 UI 视觉配方：建立在框架 `框架/界面/` 控件之上的格式、效果和配色，不重写命中、滚动或输入隔离。

玩法状态、计时、输入、特效编排和存档仍留在场景与玩法代码；配方只接收位置、尺寸、文案和回调。跨游戏通用的控件继续从 `框架/界面/` 直接用，不在这里再包一层。

引擎无关的立即模式绘制契约（`图形对象`、文字样式、纹理帧引用）统一定义在 GM `游戏模块库/框架/界面/绘制/协议.ts`，项目从 `项目:框架/界面/绘制/协议.ts` 直接引用；协议不导入 Three 或 Phaser 运行时。`组件/霓虹街机/` 与 `代码/视觉/` 只保留“画什么”的共享配方；Phaser Graphics 与 Three 后端结构兼容同一协议，接线由 `测试/绘制接口.test.ts` 验证。`组件/绘制/` 继续存放游戏实际使用的玻璃绘制配方，不产生看板预览样品。

## 当前配方

`霓虹街机/`：从对局、开始菜单和设置页抽出的第一套。

- `调色板.ts`：本项目界面配色的语义入口；可按夜空鎏金、暖纸古典、青蓝未来分别读取 GM 框架主题，不把单一当前主题误当成全部配色。方块颜色独立来自 `代码/视觉/外观/方块外观.ts`，经 `游戏外观.方块.颜色` 读取，不随界面主题改变。
- `文字.ts`：包装框架 `界面文字`，统一使用 `游戏外观.字体`；另提供带描边/字距的原生文字配方，供场景内需要直接读取 `.text`/`.style` 的说明文字使用。
- `文字样式.ts`：霓虹文字角色表（标题/金币/按钮/角钮/模式卡/风景…），字号、字重、颜色、描边集中一处；`文字.ts` 的 `添加霓虹文字项` 把 `文字项` 建成 Phaser Text，Three 版用画笔渲染同一份 `文字项`。
- `底板.ts`：游戏主题的霓虹玻璃（面板底/描边/地点纹样/角饰）；引擎无关的柔影/玻璃面板/玻璃按钮原语已收敛到 `组件/绘制/玻璃绘制.ts` 并由本文件 re-export，`绘制霓虹玻璃` 默认取当前主题的面板底色与描边。
- `按钮.ts` / `按钮配方.ts`：包装框架 `界面按钮`，取调色板的按钮变体，命中与手势仍复用通用按钮；底板与文字色由 `绘制霓虹按钮` 等纯函数给出，Three 版直接调用。
- `模式卡.ts` / `模式卡配方.ts` / `模式装置.ts`：模式选择卡是蓝色入口牌，左侧槽位按模式画攀升、冲刺、时限或当日方块；右上角排行是小牌。返回是一块居中的厚按键，短文案左右各一颗同色方块；模式选择页待机轻浮，按下即沉，点击后立刻离开。模式选择、纯享、成就、排行榜和商店退出共用这块按键。文字项来自纯配方，数据由 `代码/界面/模式卡数据.ts` 接入。
- `主界面布局.ts`：`计算主界面布局(视口宽, 视口高, 状态)` 提供菜单态/模式选择态/纯享态几何与主界面静态文字项，Phaser `代码/场景/主界面/开始菜单.ts` 与 Three 主界面共用。
- `纯享配方.ts`：纯享风景态的胶囊按钮、风景标题/副题文字项、底部圆点与布局，Phaser `代码/界面/纯享风景.ts` 与 Three 主界面纯享态共用。
- `页面配方.ts`：设置/列表类页面视觉（覆盖页面板、分组标题与分隔线、滑块、下拉框、开关、列表行与进度线、页签），Three 设置/成就/排行榜/商店页自绘使用。
- `外观卡配方.ts`：外观标题牌与外观卡（样式/背景/方块缩略、标签文字项、列表常量），Phaser `外观卡.ts` 委托绘制，Three 设置/商店页共用。
- `方块单元.ts`：棋盘格、活动块、投影和预览块共用的程序化方块单元绘制；支持宝石斜面、柔瓷圆角釉面、铬金渐变反射与拉丝、像素硬边与点阵。方案数据在 `代码/视觉/外观/方块外观.ts`，幽灵轮廓及辉光随质感调整。
- `外观卡.ts`：设置页的竖排标题牌和样式/背景外观卡；主题缩略图使用当前配方。预览中的样式与背景共用单排列表，复用框架横向滚动、交互裁剪，支持滚轮、空白处拖动和前后按钮，内容增多不换行。
- 对局 HUD 由 `代码/视觉/对局布局.ts` 计算、`代码/应用/视觉/对局绘制.ts` 接入现有玻璃配方：模式徽章与分数优先；手机侧栏压窄为暂存管段、连续向上传输的预览管道与纪录卡，棋盘按整数格距等比放大。暂存、队列和纪录用图形标识，队列上移并飞入棋盘，暂存通过交换飞行反馈，移除重复的侧栏硬降入口，硬降沿用底部双击与键盘空格。
- `对局侧栏配方.ts`：手机连续管壁、导轨和端口套箍；桌面侧栏玻璃底板、分隔线与最佳纪录页脚。
- `对局仪表.ts`：等级舱、主仪表和副读数连成分段装置；马拉松以分数为主，每日挑战以当前/目标行数为主，冲刺在左槽显示累计用时、保留当前/目标行数，极限在右槽显示逐步紧迫的倒计时；两个模式不再占用 HUD 与棋盘之间的独立时钟行。消行流光击中分数后，数字才滚动增长，数值追赶复用框架数值面板。
- `操作键配方.ts`：竖屏对局底部六键。实心倒角厚键放在一块托盘里，旋转键用大号粗实回转箭头，六键始终只画图形，图标位于键面中心；移动键采用方向轮廓，下落键呈向下形。中上键直接暂存，左右转负责旋转；下落键单击软降、双击硬降，不再显示操作文字或双击文案。角键只显示离开与暂停/继续图形。
- `操作说明卡.ts`：操作标题、键位说明和快速移动提示。
- `结算演出.ts`：方块结算台、T形落位、新纪录爆炸章、计分落定与操作反馈。分数和本局金币常驻；到账和成就提示在独立区域上移淡出，寿命复用框架轻提示队列。入场后保留浮动、闪耀、流光和按钮呼吸，提示区轮播本局收藏；操作复用真实按钮与独占控件层。

GM 看板「资源 → 界面」构建`组件/预览/界面资源.ts`：30项真实样品，包括5组件、2样式、1布局、5业务应用、2套件、1个含15方案的配色样品、4按钮家族、6图标组、4特效；方块单元接入16套外观。「方块结算」可持续播放或定格入场/奖励/成就/待机阶段，支持中英文与省电，复用真实配方而不读写存档。主题通过`界面主题目录`独立登记：霓虹街机是视觉主题，15套配色是它的方案；旅行收藏是组合套件。主题预览集中设置，不修改游戏存档。

`按钮样品.ts`将菜单（主要/次要/普通/覆盖页）、纸墨（金/纸/墨）、风景胶囊、操作键作为4种结构家族；尺寸、文案、配色是应用调整，悬停和按下走框架真实控件输入，特殊状态在详情查看。`图标样品.ts`按导航、系统、成长、收藏、交易单用途分组，7个图标各显示一次，每组登记一张图集与帧坐标。按钮每家族一张同源透明底板，满足严格像素重复时显示九宫，支持PNG/JSON下载；不生成状态图片。配色、样式、布局无图集。

`登记()`条目始终切到当前配色：套件/应用/布局/配色才铺主题大背景，组件/样式不追加主题底，中性画布由 GM 提供；按钮、图标样品文件各自负责预览底，登记层不再叠加第二层主题背景。方块单元以`陈列状态: "外观"`让 GM 将16种外观展开为并排卡；普通预览保留7色并显示外观名称，高度压到150。方块固定资产只登记一个中性白色基元（方案取当前外观，格子32、原点16,16），说明同结构复用、颜色由程序配方生成；宝石/金属明暗是非线性调色，简单乘色不能完全复现原样，游戏运行时渲染不变。

底板与纸面板固定资产直接调用同源配方，在16,16以48×48紧凑尺寸绘制；覆盖页面板仍调用对应实际配方，侧栏分隔线保持运行时叠加、不烘焙，300×220大样不裁成很长的九宫。底板自身配方不改，资产检测与真实渲染走同一入口。

样品直接调用本项目配方与框架控件，不要求游戏服务在线。独立入口先隔离持久存储；原`组件目录.ts`仍供游戏消息协议使用，不充当资源工作台渲染入口。

`组件/预览/特效样品.ts` 在「资源 → 特效」调用 `代码/视觉/特效配方.ts` 的消行光带、四行庆祝、硬降拖尾和锁定闪光，保留真实时长，每1.5秒循环；可暂停并按进度定格，不进入对局或写存档。性能区分完整预览画布与独立动态层峰值，且只运行所选特效。这四项没有图片调用，显示“无”；不能代替整局与手机实测。

## 接入

场景从 `代码/界面/` 取已经接好玩法的配方（读文案、设置、存档并接回调），`代码/界面/` 再转调这里的纯视觉配方。需要玩法专属组合时，场景可以直接用 `组件/霓虹街机/` 的配方，仍然不读存档、不决定规则。

## 验证

- 游戏方块：项目根执行 `bun 测试/浏览器/方块外观.ts [游戏地址]`（默认 3220），以 Chrome 在 1280/430 下通过真实设置入口选择四种外观、检查保存与刷新、旧设置保留及棋盘/预告/暂存画面；产物位于 `reports/block-appearances/`。方案完整性与旧值回退由 `测试/方块外观.test.ts` 检查，不代表完整玩法或设备性能验收。

- 界面预览：在看板「资源 → 界面」选择条目、特殊状态、方块外观或按钮变体，主题在独立页面设置；检查独立画面、查看实际源码并导出交付。GM根执行 `bun 测试/浏览器/看板/界面资源.ts` 验证全部登记、15配色/16方块、存储隔离、真实点击和同状态PNG。右键AI修改使用真实导出和精简上下文，草稿文件只在独立设计中生效。
- 实机：在真实对局、开始菜单和设置页确认按钮、模式卡、侧栏、操作说明与结算仍走同一套配方（见根 `README.md` 的实机验收脚本）。

旅行版的样式、背景、方块都用 `外观卡.ts` 的横向单排列表，卡片调用真实风景与方块渲染器，不以文字符号代替缩略图。`旅行纹样.ts` 在方块和面板角饰共用12种地域纹样；`图标.ts` 绘制关闭、金币、风景、设置、成就和商店纹理，按钮手势仍复用框架。GM颜色分类同时登记15套主题与16套方块，选择后在面板应用，两组相互独立；预览不授予商品、不改玩家收藏。

成就收藏、商店目录、设置纵向条目与外观横排使用框架 `列表`，默认按实际控件工作量与CPU耗时选择普通/虚拟模式；页面自绘只绘制可视项，成就行按框架项矩形横向居中，滚动和惯性复用 `滚动容器`。风景缩略图使用真实背景配方，按缩略图、横排与设置面板的屏幕矩形逐层裁剪，图元不会溢到相邻卡片。商店底板直接使用圆角配方。设置与成就隐藏竖向滑轨，保留滑动。

外观选择列表以横排标题和全宽卡片区显示，卡片上可直接拖动；货币使用金色 O 形四格方块图标，余额与商店费用共用同一纹理。菜单按钮不叠加固定深色文字描边，文字颜色仍跟随底色。

## 设计草稿与正式构建

看板新建设计保存在 `项目:组件/草稿/<编号>/`，含记录、独立配方和接入备份，可随项目保存。类型检查排除未完成草稿，正式构建明确拒绝导入草稿目录；仅在看板设计预览中加载。底板与信息侧栏合并为一个底板资源的形态，纸面板保留材质差异；可严格还原的图集九宫压缩，分隔线保持叠加图元。

主题页并排预览实际控件与配色。布局支持按真实逻辑尺寸查看和缩放平移。背景与金币条有独立预览；其他正式入口加载的资源可从资源索引按导出或使用页面搜索，未独立预览的模块明确标识源码资源。

`霓虹街机/成就图标.ts` 为全部12项成就提供不同的32×32程序徽章，成就页按解锁状态使用主题色；资源目录可检索每项图标，独立预览的「成就徽章」展示同一组12帧。商店按钮使用合法中文字体与14/16px字号，部位/地点标签为14px；模式卡标题24px，说明、目标、纪录14px并留出边界。
