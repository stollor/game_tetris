# 项目 UI 组件

这里存放俄罗斯方块项目专属的 UI 视觉配方：建立在框架 `框架/界面/` 控件之上的格式、效果和配色，不重写命中、滚动或输入隔离。

玩法状态、计时、输入、特效编排和存档仍留在场景与玩法代码；配方只接收位置、尺寸、文案和回调。跨游戏通用的控件继续从 `框架/界面/` 直接用，不在这里再包一层。

## 当前配方

`霓虹街机/`：从对局、开始菜单和设置页抽出的第一套。

- `调色板.ts`：本项目界面配色的语义入口；可按夜空鎏金、暖纸古典、青蓝未来分别读取 GM 框架主题，不把单一当前主题误当成全部配色。方块颜色独立来自 `代码/配置/方块外观.ts`，经 `游戏外观.方块.颜色` 读取，不随界面主题改变。
- `文字.ts`：包装框架 `界面文字`，统一使用 `游戏外观.字体`；另提供带描边/字距的原生文字配方，供场景内需要直接读取 `.text`/`.style` 的说明文字使用。
- `底板.ts`：包装框架 `绘制玻璃面板`，默认取当前主题的面板底色与描边。
- `按钮.ts`：包装框架 `界面按钮`，取调色板的按钮变体，命中与手势仍复用通用按钮。
- `模式卡.ts`：模式选择卡（整卡是按钮，叠标题/细节/说明/纪录）。
- `方块单元.ts`：棋盘格、活动块、投影和预览块共用的程序化方块单元绘制；支持宝石斜面、柔瓷圆角釉面、铬金渐变反射与拉丝、像素硬边与点阵。方案数据在 `代码/配置/方块外观.ts`，幽灵轮廓及辉光随质感调整。
- `外观卡.ts`：设置页的竖排标题牌和样式/背景外观卡；主题缩略图使用当前配方。预览中的样式与背景共用单排列表，复用框架横向滚动、交互裁剪，支持滚轮、空白处拖动和前后按钮，内容增多不换行。
- `对局顶栏.ts`：对局顶部信息栏与模式提示文字。
- `对局侧栏.ts`：侧栏玻璃底板、分隔线与最佳纪录页脚。
- `操作说明卡.ts`：操作标题、键位说明和快速移动提示。
- `结算面板.ts`：结算遮罩、玻璃面板、徽标、分数、统计和操作按钮。

`预览/` 是 GM 看板入口，协议逐字复制 GM 的 `游戏模块库/UI组件库/预览/预览协议.ts`。颜色页按「主题-名称」「方块-名称」展示31套方案（15套主题、16套方块，含12套地点外观）。选中只查看，右侧「使用此配色」才应用，已生效卡片和面板显示「已使用」；主题与方块分组独立，各相关样品共用当前组合。GM 刷新、跨库返回、分享和交付保留组合，不写玩家设置；实际游戏在设置页选择方块外观并保存。外观卡点击会选中颜色页中的对应主题。按钮默认提供真实禁用对照；背景卡与设置页共用配置。动效复用游戏的落块、消行及背景绘制器，重绘时清理回调。图标分类登记「方块单元」与「旅行图标」，后者把 `图标.ts` 的关闭/金币/风景/设置/成就/商店按独立按钮陈列，不共用背景。

## 接入

场景从 `代码/界面/` 取已经接好玩法的配方（读文案、设置、存档并接回调），`代码/界面/` 再转调这里的纯视觉配方。需要玩法专属组合时，场景可以直接用 `组件/霓虹街机/` 的配方，仍然不读存档、不决定规则。

## 验证

- 游戏方块：项目根执行 `bun 测试/浏览器/方块外观.ts [游戏地址]`（默认 3220），以 Chrome 在 1280/430 下通过真实设置入口选择四种外观、检查保存与刷新、旧设置保留及棋盘/预告/暂存画面；产物位于 `reports/block-appearances/`。方案完整性与旧值回退由 `测试/方块外观.test.ts` 检查，不代表完整玩法或设备性能验收。

- 预览：看板打开「当前项目组件」，逐个切换样品与设定，确认配色、尺寸和状态。
- 动效预览的逐帧回调随实际图层或特效销毁而注销，切换设定时不会继续更新旧对象。看板运行后，在项目根执行 `bun 测试/浏览器/UI套件背景.ts`（默认 4175，支持 `PORT`），检查四种背景在 1440/430 宽下反复切换、持续动画、重置、分类返回及看板内嵌切换；截图位于 `reports/ui-suite-background/`。使用软件 WebGL，不代表硬件性能验收。
- 实机：在真实对局、开始菜单和设置页确认按钮、模式卡、侧栏、操作说明与结算仍走同一套配方（见根 `README.md` 的实机验收脚本）。

旅行版的样式、背景、方块都用 `外观卡.ts` 的横向单排列表，卡片调用真实风景与方块渲染器，不以文字符号代替缩略图。`旅行纹样.ts` 在方块和面板角饰共用12种地域纹样；`图标.ts` 绘制关闭、金币、风景、设置、成就和商店纹理，按钮手势仍复用框架。GM颜色分类同时登记15套主题与16套方块，选择后在面板应用，两组相互独立；预览不授予商品、不改玩家收藏。

风景缩略图通过 `霓虹街机/风景裁剪.ts` 复用框架滚动区域的遮罩，单卡裁剪随父容器移动，不接收触控。设置与成就隐藏竖向滑轨，保留滑动。

外观选择列表以横排标题和全宽卡片区显示，卡片上可直接拖动；货币使用金色 O 形四格方块图标，余额与商店费用共用同一纹理。菜单按钮不叠加固定深色文字描边，文字颜色仍跟随底色。
