# 配置导航

| 文件/位置 | 内容与真相源 | 修改入口 |
| --- | --- | --- |
| `项目设置.json` | 项目名称、目标平台、测试与打包尺寸；GM工具读取，不是玩家偏好 | GM看板项目设置 |
| `配置表.json` | 已确认的玩法运行参数，字段与值在同一份表；项目配置组合入口读取 | GM配置表及其校验/草稿保存 |
| `TapTap发布.json` | 渠道公开配置、榜单、成就与发布资料；当前平台接入读取公开字段 | GM发布工具 |
| `../代码/框架配置/` | 给框架注入的主题/音乐/音效等表 | 项目源码与真实预览 |
| `../代码/项目配置/` | 玩法配置组合及项目价格/奖励规则 | 项目源码与规则测试 |
| `../代码/设置/` | 玩家偏好默认值与项目存档接入，运行值来自存档 | 游戏设置界面 |
| `../代码/视觉/外观/` | 外观参数和读取规则，和真实绘制共用 | GM资源定位的项目源码 |

文档只说明规则，不重复维护运行数值。发布配置与客户端公开配置尚未进一步拆分；这次不变更发布协议。正式/草稿资源状态由资源登记维护，草稿不进入构建。构建、截图、日志与报告不放进配置目录。
