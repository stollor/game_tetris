# 开发规范

## 技术栈

- Runtime 和包管理：Bun
- 语言：TypeScript
- 格式化和 Lint：Biome
- 单元测试：Bun 内置测试运行器
- 浏览器自动化：Playwright；GameMaker 的 `browser test` 使用项目内的状态流程

使用 Bun 管理依赖，不引入 npm、pnpm、yarn、ESLint、Prettier 或 Jest。

## 命名和代码

- 游戏业务目录、文件、类型和函数使用中文；生态配置名和标准 Web API 保持英文。
- 避免中英混合命名。
- TypeScript 使用清晰的数据结构和明确的函数参数、返回值；不使用 `any` 逃避类型问题。
- 目录按实际职责命名，不为未来可能的需求预建抽象层。

## 修改后检查

```sh
bun run check
bun run typecheck
bun test
bun run build
```
