# 再消一行

首发目标为 TapTap H5。工程目录与源码标识已改为 `再消一行`；`neon-pulse:*`、`gamemaker:settings` 存档保留，旧 `俄罗斯方块:设置` 会在启动时迁移到 `再消一行:设置`，更名不会清除旧纪录。未购买旅行外观也能使用原有免费样式、背景与四套方块。

## 旅行收藏

新增成都熊猫、丽江雪山、万里长城、紫禁朱墙、西湖烟雨、敦煌流沙、桂林山水、苏州园林、重庆夜航、长安灯市、黄山云松、拉萨晴空12套。每套有静态背景、动态背景、界面样式、方块外观、16项成套音效、一首原创音乐。地域意象为原创程序绘画和曲谱，不使用景区照片、商标素材或现有歌曲。

背景构图、方块纹样及材质各有区别：竹林熊猫、雪山冰晶、山脊城砖、朱墙宫阙、荷叶涟漪、沙丘驼队、漓江竹筏、园林窗棂、江城霓虹、城楼铜纹、云海松针、晴空织锦。UI使用对应语义主题与角饰；游戏规则、计分和碰撞不随外观改变。

在商店选择地点，可放大静态/动态风景、试听音乐与音效。商品先进入确认面板，显示余额、价格和不足金额；成功保存才扣币并授予。购买后选择使用，单件可以与其他地点混搭，也可以一键穿戴整套。设置中的样式、背景、方块均为真实缩略图单排列表，支持横向移动，仅显示免费与已拥有内容。

## 金币与价格

金币与定价运行值在 `代码/项目配置/旅行皮肤.ts` 维护，视听接入参数在 `代码/框架配置/旅行地点.ts`。当前数值是首发初始配置，需要玩家试玩后评估平衡。

- 新收藏起始120金币；每项真实解锁成就60金币。旧成就首次进入旅行版时补领一次。
- 完成对局且有效时间满30秒、至少落块10次：基础20，表现为分数每1000分加1、每消行加2，表现部分最多60。
- 按北京时间计算，每日首个有效结算额外50；突破已有个人最佳纪录额外35。首个个人纪录不计“突破已有纪录”。冲刺按有效完赛时间比较，其他模式沿用原分数纪录比较。
- 直接退出未结束对局不结算对局金币；成就奖励已经独立保存的部分保留。
- 四档价格：静态80起、动态180起、UI140起、方块120起、音效100起、音乐160起；地点档位增加0–3档，静态每档加10，其他每档加20。
- 动态包含同地点静态。已有静态再买动态只补差价；套装按未拥有内容72折、向上取整到10金币，已经拥有的内容不重复收费。

余额、所有权、对局结算编号和成就领取编号在 `旅行版:收藏` 的同一份版本1存档写入。操作读取最新余额；支持 Web Locks 的浏览器同源多页签串行修改。坏档、未知版本、空间不足和写入失败不扣款、不授予、不覆盖原文；结算保存失败可点击奖励文字重试，相同对局编号仍只结算一次。恢复默认设置不清空金币、收藏、成就或纪录。

## 交互

主菜单以风景为底。左上角是带底板的金币条，设置、成就、商店三个图标按钮在金币条下方纵向排列，不与游戏名称重叠；开始游戏在底部。进入模式选择时这三个按钮会像进入纯享一样移出。点风景或上滑进入纯享时菜单移出，返回键在右下角且不带关闭图标；左右滑动切换风景，下滑或返回退出。菜单不播放下落消行方块，也不自动播背景曲；每处风景循环对应的环境声。商店全屏试穿套装：底部仍是横向滑动的套装目录；套装内六项内容用两行网格展示，最下一行是当前部件价与整套价两个购买按钮。选地点即试听该套音乐。点选静态/动态会切换背景，点界面在风景上叠 UI 示意，点方块按对局格子大小陈列七种方块，点音效试听该套效果，点音乐弹出「正在播放」提示。设置里的样式、背景、方块同样只靠滑动列表，不设箭头。设置、购买确认和暂停相关弹窗支持点击外侧空白关闭，并消费事件防止穿透。关闭按钮使用绘制的图标纹理。手机按键默认显示功能说明，可在设置关闭；控制方式和长按/双击规则沿用原实现。

## 发布与验证边界

正式包由 GM `bun run gm -- 打包游戏 再消一行` 生成到 `产物/`，清理旧哈希并外置压缩后的 Phaser。`index.html` 是入口；目录整体作为静态H5发布，不能直接以本地 `file://` 打开模块包。

`测试/旅行收藏.test.ts` 覆盖目录、价格、差价、折扣、奖励幂等、失败与保护。`测试/浏览器/旅行版.ts` 读取实际发布包，用隔离存档验证购买/穿戴与对局奖励；12套视觉专项使用测试浏览器资金，不修改用户真实存档。`旅行音频.ts` 输出实际Web Audio采样。`分辨率适配.ts` 检查窄屏到4K。截图与音频放在忽略的 `reports/` 下。

当前金币、收藏与纪录保存在本机浏览器。尚未接入账号同步、TapTap云存档或服务端经济校验，因此不能承诺跨设备恢复或防止本机数据被修改。TapTap的[云存档官方指南](https://developer.taptap.cn/minigameapidoc/dev/tutorial/open-capabilities/cloud-save-tutorial/)要求平台环境中的文件写入和云端同步；浏览器验收不等于已经完成该接入。

正式上线仍需在TapTap实际客户端检查触屏、安全区域、音频首触解锁、切后台恢复、存储持久化和渠道审核；本机Chrome与设备模拟不能替代这些结果。尚未执行渠道上传或发布。
