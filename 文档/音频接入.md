# 音频接入

音频分为背景音乐与音效两层，都通过 `框架/音频/音频.ts` 的注册表播放，不再由游戏自己写 `setInterval` 逐拍调度。

## 背景音乐

- 基础菜单与对局是两个 `曲谱` 条目（`俄罗斯方块.菜单`、`俄罗斯方块.对局`），定义在 `代码/框架配置/音乐.ts`。
- 另有12首旅行曲谱，编号 `旅行.<地点名称>`。菜单和对局默认不播放背景曲；商店选地点即试听该套音乐 18 秒，点「音乐」只提示正在播放，关闭商店会停。所有旋律为原创程序曲谱。
- `代码/音频/俄罗斯方块程序音频.ts` 在加载时 `注册音乐库(音乐库)`。需要时仍可调用 `播放俄罗斯方块音乐("菜单" | "对局")`。
- 16处风景的环境声在 `代码/框架配置/场景氛围.ts`，由 `播放场景氛围` 循环，走独立氛围输出。

## 暂停与恢复

框架的曲谱播放只有 `停止游戏背景音乐()`，没有暂停/继续。因此：

- 对局暂停或结束时：`设置俄罗斯方块音乐暂停(true)` → `停止游戏背景音乐()`，音乐淡出停止。
- 对局恢复时：`设置俄罗斯方块音乐暂停(false)` → 重新 `播放游戏背景音乐(当前曲目)`。

与迁移前相比，暂停不再“记住播放位置”。原先是手写调度器暂停后从原来的拍点继续；现在是停止后从头重放当前曲目。对局暂停通常很短，且恢复的是整段循环曲，这是可接受的取舍。若以后框架提供曲谱暂停/继续，改回调用框架即可，调用方（场景）不用再散改。

## 音效

- 基础十六种音效与12套地域音效（每套16项，合计208项）登记在 `代码/框架配置/音效.ts` 的 `音效库`（合成谱）。
- `注册音效库(音效库)` 统一登记；`消行`/`连击` 依赖消行数或连击数，由游戏用 `注册程序音效` 动态覆盖同名 id，并在注册表里保留代表谱供看板试听。
- 合成谱音量已并入原实现额外乘的 `0.82` 系数，实际响度与迁移前一致。

## 验收

改动音频后至少运行 `bun run check`、`bun run typecheck`、`bun test`、`bun run build`。实际发声与节流由 `测试/落块体验验收.ts` 在真实页面采集音效样本验证。

旅行音频采样入口：`bun 测试/浏览器/旅行音频.ts`，用实际编排器展开完整乐段，经Web Audio生成样本，检查12首音乐和192项音效非静音、无削波，保存音乐和消行WAV供试听。它不替代TapTap客户端的音频解锁、静音、切后台和蓝牙设备实测。

背景音效是风、雨、水等风景氛围，默认0。它复用框架音频上下文并建立独立增益输出，不经过交互音效或音乐总线；切换风景、调节设置时停止并断开旧输出。

音乐滑块会同步保存启用状态，首次与恢复默认均为0；菜单和对局登记当前曲目，调高音量即可播放。一次触屏拖动在确定方向后只归一个滚动区域，横拖穿过相邻外观行也不会带动它们。
