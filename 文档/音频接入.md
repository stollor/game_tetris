# 音频接入

当前游戏使用 Three 版 Web Audio 服务，音乐、音效和风景氛围均从 `代码/three版/音频/index.ts` 接入；曲谱与效果表分别位于 `代码/框架配置/音乐.ts`、`代码/框架配置/音效.ts` 和 `代码/框架配置/场景氛围.ts`。

浏览器要求用户手势后才能播放。Three 启动入口会在首次触屏或按键后解锁音频上下文。设置页统一调节背景音乐、音效与氛围音量；失焦或页面隐藏时停止氛围声源，恢复后根据当前设置重建。

暂停或结束对局时，当前曲目淡出并停止；恢复对局时从头播放当前曲目。此行为由 Three 音频服务统一管理，页面只发起播放、停止和音量更新请求。

验收命令：`bun run typecheck`、`bun test`、`bun run build`。浏览器音频验收需要检查首次手势解锁、暂停恢复、页面隐藏恢复和音量归零；浏览器测试不替代 TapTap 客户端与真机验收。
