# 游戏测试接入

`测试桥/` 汇总标准快照、功能命令、性能观测及资源压力；`验收样本.ts` 准备固定棋盘；`主题预览.ts` 连接GM主题与组件目录。启动层只在 `import.meta.env.GM_TEST === "1"` 时接入。单元测试通过 `测试/准备.ts` 开启，开发/内部包由GM构建器注入，外部包全部裁剪。

真实按钮绘制完成后通过框架 `开发/资源使用.ts` 记录路径与导出，标准桥只在真正提交帧后发布。GM核对统一开发构建器的输入摘要和实际构建号，不能用独立预览或旧页面验证新源码。GM根 `测试/浏览器/看板/资源运行闭环.ts` 串行验收并恢复临时源码注释，结果不等同所有按钮状态或玩法验收。

主题桥沿用标准提交帧，读取游戏缓存的有效主题槽位；临时预览覆写不提供正式主题证据。GM根 `测试/浏览器/看板/正式主题应用.ts` 临时保存成都熊猫并恢复极光原野，覆盖新版本、完整槽位、玩家偏好与恢复；不会修改玩家真实存档。

浏览器功能与性能流程统一在 `测试/浏览器/`。画质、省电和帧率策略仍属于实际运行代码，不随测试一起删除。`测试/包体边界.test.ts` 验证外部包模块占用与公开配置投影。
