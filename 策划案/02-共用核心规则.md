# 阶段 2：正式版共用核心规则

本文件在 MVP 验收通过后生效，并取代 01-最小MVP.md 中标明为简化的规则。所有游戏模式共用本文件的棋盘、方块、随机序列、旋转和锁定规则。

## 棋盘与坐标

- 10 列、20 行可见区；上方 2 行隐藏缓冲区。
- 列从左至右为 0–9；可见行为 0–19；隐藏行为 -2、-1；行号向下递增。
- 新方块按下表出生在隐藏区是预期规则；其进入可见区前不会绘制为棋盘内的方块，不属于出生失败或异常。
- 越过列 0/9、行 -2/19 的位置视为出界，碰撞检测时出界格不可放置。
- 满行扫描整场 22 行，隐藏行满行也参与消除、计分、升级和连击。

## 方块形状与出生占格

格坐标写为 (列, 行)，初始朝向为 0。

| 方块 | 出生占格 |
|---|---|
| I | (3,-1)、(4,-1)、(5,-1)、(6,-1) |
| O | (4,-2)、(5,-2)、(4,-1)、(5,-1) |
| T | (4,-2)、(3,-1)、(4,-1)、(5,-1) |
| S | (4,-2)、(5,-2)、(3,-1)、(4,-1) |
| Z | (3,-2)、(4,-2)、(4,-1)、(5,-1) |
| J | (3,-2)、(3,-1)、(4,-1)、(5,-1) |
| L | (5,-2)、(3,-1)、(4,-1)、(5,-1) |

T/J/L/S/Z 以 (4,-1) 为旋转中心；I 以 (4.5,-0.5) 为中心；O 占格恒定。旋转朝向按 0→R→2→L→0 循环。

## 随机序列

- 使用 7-bag：固定顺序 [I,O,T,S,Z,J,L] 经过 Fisher–Yates 洗牌，每袋七种各出现一次。
- 不允许从七种方块中独立等概率抽取（那会出现连续缺块）。
- 正式非每日模式允许使用游戏随机源。逻辑测试必须允许提供固定随机源或固定序列。
- 每日挑战的种子算法单独定义在 06-模式-每日挑战.md。

## 旋转与踢墙

- 正式模式使用 SRS：JLSTZ 共用一套五次试探表，I 方块使用独立五次试探表，O 只允许零偏移试探。
- 每次旋转先构造目标朝向，再按目标朝向与目标位置做碰撞检测；依踢墙表顺序找第一个合法位置。全部失败则位置与朝向均保持不变。
- 适配本棋盘“行向下为正”的坐标时，将标准 SRS 表中的纵向偏移取反，水平偏移和试探顺序不变。
- 完整踢墙矩阵以来源项目 src/core/srs.js 中 KICKS_JLSTZ、KICKS_I 为数据基准；实现前应将这些表复制为测试数据并验证所有 8 种 90° 转向组、每组 5 个试探。不能只测零偏移成功的普通旋转。
- 180° 旋转默认开启，依次试探 (0,0)、(0,-1)；可以在设置中关闭。
- O 方块旋转可更新朝向状态，但占格不得变化。

## 固定、消行与失败顺序

- Lock Delay 为 500ms。触底期间成功移动/旋转可重置延迟，最多重置 15 次；第 16 次成功操作立即固定。离开地面时锁定计时归零，但重置次数不回退。
- 锁定后的判定顺序：① Lock Out；② 扫描并消除整场满行；③ 结算；④ 产生下一块；⑤ 检查 Top Out。
- Lock Out：方块锁定时，若四格全部位于可见区之上，则立即结束，本次不消行。
- Top Out：新方块出生格与已有方块重叠或不能放置时结束。
- 消行完成后，其上方所有行整体下移。多行消除必须一次性按行标记并重建棋盘，不得用旧索引逐行删除造成错位。

## 操作手感参数

- DAS 133ms：方向键按下时立即移动一格；持续按住后，133ms 首次自动横移。
- ARR 33ms：首次自动横移后每隔 33ms 横移一格；dt 超过边界时保留溢出，不能因帧率不同累积漂移。
- Lock Delay 与 Move Reset 按本文件上文实现。
- 正式重力曲线、软降速度、得分和暂停计时以具体模式文件及 03-默认模式-马拉松.md 为准。

## T-Spin 判定

- 锁定时，当前方块必须是 T；本块最后一次有效操作必须为成功旋转；以旋转中心为基准的四个对角格至少 3 格被占用或出界，才满足 T-Spin 基本条件。
- 成功旋转后，成功的左右移动或实际产生额外下落格数的软降会取消“最后操作为旋转”。自然重力下落和硬降不取消。失败的操作不改变判定状态。
- 暂存（Hold）是当前版本已实现操作：每个当前方块在锁定前最多使用一次；首次暂存会从预告队列取一块，之后与已有暂存块交换不推进队列。换入方块使用出生朝向，并清空本块旋转判定状态、重置锁定计时。新局清空暂存；暂停和结束状态不接受暂存。键盘 C 或 ↑ 长按 450ms 可触发；触屏手势见 `文档/功能策划/controls.json`。
- 满足基本条件后，两枚朝向前角都被占用/出界，或本次旋转使用对应踢墙表的最后一个候选，判为 Full；否则为 Mini。候选编号从 0 开始：90° SRS 表的最后候选是 index 4；180° 表只有两个候选 `(0,0)`、`(0,-1)`，其最后候选 index 1 同样视为 Full。
- 消 2 行或更多的 T-Spin 一律为 Full。Mini 最多消 1 行；Full 可以消 0–3 行。
- 完整旋转中心、前角方向和 90° kick index 数据以来源项目 docs/framework.md §5.3、§5.4 和 src/core/srs.js 为准；180° 的两个候选按本文件明确的顺序与最终候选规则处理。测试需分别覆盖旋转判定和消行分类，不得只验证方块转动。

## 暂停与单局状态

- 单局状态至少区分进行中、暂停、结算。暂停时冻结重力、锁定延迟、自动横移、消行动画和模式计时；恢复时从冻结值继续，不得在暂停期间暗中推进。
- P 或 Esc 切换暂停/继续。游戏结束后玩法输入不再改变棋盘或成绩；只有“重新开始”能初始化新局。
- 模式计时以具体模式的定义为准，但所有模式的暂停累计时间都不计入有效用时。
