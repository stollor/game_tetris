# 再消一行宣发资料

`资料.json` 与 `素材/` 是本游戏独立的宣发资料，GM总览游戏库和发布渠道共用。名称、介绍、标签、主题色、封面与渠道版本可在“总览 → 管理宣发资料”编辑，也可调用 GM `宣发` 命令。

现有 `运营/taptap/` 三张图片已按内容摘要收录独立副本，原文件保留。后续选用的新图、真实截图和MP4实录同样通过收录操作进入资料库；不把临时reports直接作为长期来源。移除资料引用不删除原文件。

TapTap渠道副本与校验回执由发布页生成，位于 `reports/宣发/TapTap/` 和 `reports/TapTap/发布/`；它们可重新生成，不改变主资料。其他渠道只记录差异文案和用途引用。
